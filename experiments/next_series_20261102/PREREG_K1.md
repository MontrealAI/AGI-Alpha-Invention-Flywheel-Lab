## Decision and complete arrangement

The beneficiary is a research group deciding which double-gene perturbations to measure after obtaining single-gene profiles. The costly activity is experimental combinatorial phenotyping. The proposed complement is a sequential allocation policy that learns from a declared number of reference double perturbations and chooses the remaining experiments. Its delivered output is a reproducible, budget-limited research allocation and its retrospective discovery record. It does not produce a cell phenotype, therapeutic result, clinical recommendation, or validated biological mechanism.

The proposed boundary crossing is specific: recover at least half of the strongest observed departures from an additive transcript-expression model in the held-out candidate pool, while measuring no more than one quarter of that pool, after charging the initial reference set. The total count includes all single profiles, the control, calibration pairs, and selected test pairs. Success on this retrospective target would justify a fresh prospective experimental-allocation test. It would not establish a generally affordable platform or an advantage over a complete specialist service.

The original Norman study already used recommender systems for genetic interactions. NAIAD (ICML 2025) supplies active combinatorial-perturbation design; BATCHIE (Nature Communications 2025) supplies a prospectively tested adaptive combination-screening arrangement; Probability-of-Hit (ICML 2026) directly targets discovery of many threshold hits. Generic active allocation is therefore rejected as a newly missing productive capability. This is a finite dependency test: do these six inexpensive single-profile summaries, counted references and a purpose-matched acquisition rule meet this particular discovery budget, or should that candidate representation be abandoned before a new experimental campaign? We claim no algorithmic novelty or superiority over the complete unexecuted NAIAD/BATCHIE systems. Competent specialists may use the same policy, calibration and retained profiles; the equal-content conventional control is expected to tie technically.

All reference outcomes in this retrospective dataset are already public. Downloading the complete workbook and analyzing every outcome with conventional software is a strong complete self-service outside option for a current buyer. Masking is solely a registered benchmark constraint intended to test a possible future campaign with genuinely unseen outcomes. This run avoids no actual assays and creates no current information scarcity, labor saving or commercial saving. A failed discovery boundary rejects the proposed budget-crossing service; a correct negative research report does not automatically become an accepted saleable substitute.

## Measurement contract and independent truth

For each unordered pair p=(A,B) and each registered readout gene g, define

`r[p,g] = mean_AB[p,g] - mean_A[p,g] - mean_B[p,g] + mean_control[g]`

and `D[p] = sqrt(mean_g(r[p,g]**2))`.

Units are author-exported log-transformed expression units, as described in the primary benchmark article's main text (p.1657). The author extractor averages the provided expression matrix; it does not independently establish the upstream normalization convention. This replay does not revalidate raw counts, normalization or log base. D measures an observed departure from additivity in the exported means. It is not fitness, a causal interaction coefficient, a p-value, or a false-discovery-rate claim. The control-ranked 1,000 genes are used without ranking by the withheld double outcomes. Pair order is canonicalized; duplicate or conflicting pair/readout records are rejected. Source means for the same single intervention and control must agree across appearances within 1e-10 absolute tolerance, otherwise affected records remain an explicit input failure.

The evaluator defines targets as the top `ceil(0.25*M)` held-out pairs by D, ties broken by canonical pair string. This target is fixed as a rank rule before observations; it is deliberately a retrospective research-prioritization contract, not a clinical or industrial qualification threshold. It provides a finite target set with an exact denominator. No transcript result substitutes for a fitness endpoint.

## Split, hidden outcomes and counted assays

All actual gene-pair lineages are indivisible split units. Sort pairs by SHA256 of `NEXT072-K1-v1|` plus the canonical pair string. The first `ceil(0.25*N)` pairs are the initial reference/calibration set. Every remaining pair is a confirmation candidate. Known single-intervention profiles for all constituent genes and the shared control are available to every policy. Shared genes may occur in calibration and confirmation: the claim concerns new combinations of measured single interventions, not generalization to unseen genes. Reversed pair labels never create a new observation.

Each policy receives exactly the same initial references and a reveal budget `B=floor(0.25*M)` among M remaining pairs. The oracle reveals D only after a policy commits a pair identity. Duplicate requests do not spend another unit and cannot return a second discovery. A full receipt records the ordered requests, predictions before reveal, values actually revealed, and remaining budget. The complete final hidden target set is used only by the evaluator after the ordered selection is sealed. The constructor must not print or inspect withheld outcome arrays to tune the policy. This is procedural isolation on a shared host, not an external blinded laboratory.

Count all unique single perturbation profiles plus one control, every calibration pair, and every selected pair. Report total profile counts alongside marginal double-pair counts. The source lacks a complete assay-cost model; profile counts are not dollars, technician hours, cells, sequencing reads, or equal laboratory costs. Validation of pooled-expression means is also not independent biological replication. The whole source set remains the denominator, including missing or rejected records.

## Fixed policies and ablations

The constructor will freeze runnable code using synthetic fixtures before the workbook download. Features use single profiles only: the two single-effect norms, additive-effect norm, effect-vector cosine, norm of their difference, and absolute norm difference. Features are symmetric in A and B. Standardization uses the candidate single-derived feature matrix; no double outcome enters it.

Primary bundle (`probability_of_hit`): Gaussian-kernel regression on revealed D, with RBF length equal to the median nonzero Euclidean distance between standardized feature vectors and ridge 0.1. Center and scale observed D using the currently revealed set. Fix threshold tau from the INITIAL reference D values only: sort ascending and take zero-based element `ceil(0.75*n_reference)-1`. This is the nearest-rank empirical 75th percentile with no interpolation. Never update tau using adaptively revealed or hidden outcomes.

For model mean mu and deviation sigma, rank candidates by `z=(mu-tau)/max(sigma,1e-12)`. The floor is an explicit numerical convention in source-expression units, not an assay-noise estimate. This ranking is monotone in the Gaussian threshold-exceedance score `0.5*erfc(-z/sqrt(2))`, which is also retained in each receipt. Ranking by z avoids spurious ties when finite-precision CDF values saturate. At sigma=0 the same floor applies; mu=tau yields score 0.5. Exact z ties use canonical pair string. Neither sigma nor the CDF score is a calibrated biological uncertainty or probability claim. Select batches of at most four before any within-batch outcomes are revealed; update the model only between batches. The evaluator's top-quarter hidden target rule remains separate from this imperfect reference-estimated acquisition threshold.

Prospective revision before public scientific freeze: the initial unpublished draft used `mean + standard_deviation` as primary. Reading the purpose-specific 2026 hit-discovery method changed that choice before any workbook access. Probability-of-Hit is now the sole primary; UCB is retained as a control. No winner will be selected after results.

Controls, all with matched single/reference/reveal permissions:

- The same bundle implemented/used as ordinary competent specialist automation. Its numerical equality is a technical tie, not measured human productivity.
- Static Probability-of-Hit: the primary acquisition with the same initial references, fixed tau and model, but no model updates during selection.
- UCB kernel ranking: the former draft primary, using `mean + standard_deviation` with updates.
- Static UCB kernel ranking: same initial references and UCB model, no updates during selection.
- Pure exploitation: same updates, acquisition uses the mean without the deviation term.
- Linear ridge regression on the same single-derived features, with ridge chosen from {0.01,0.1,1,10} by leave-one-reference-pair-out squared error; no confirmation outcomes used for tuning.
- Additive-effect magnitude ranking, using the norm of A+B-2*control; it does not pretend that a linear predictor can directly predict a nonzero interaction residual.
- Diversity allocation: select the pair farthest in feature space from all already observed pairs, with fixed ties.
- No single-profile features for ranking: one constant feature, primary Probability-of-Hit acquisition and the same budget. The independent outcome oracle still needs the constituent single profiles, and they remain charged; this removes the representation complement without pretending those measurements were unnecessary.
- 32 fixed hash-order allocations, salted `NEXT072-RANDOM-00` through `NEXT072-RANDOM-31`, all reported, never selected after observing their success. These are finite random-order controls, not independent biological trials.

The published GEARS/CPA/foundation results inform the comparator choice but are not relabeled as matched executions: their training splits differ. No model is handicapped by withholding calibration allowed to the proposal. A current complete specialist may use the identical bundle. No advantage over an unexecuted deep model or full commercial laboratory is claimed.
