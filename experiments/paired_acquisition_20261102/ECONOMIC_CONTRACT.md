# Prospective acquisition choice and cost frontier

## Status, purpose and ownership

This is the proposed economic decision contract for the independently owned paired-acquisition successor. The coordinator must freeze it, `economic_frontier.py`, the scientific and verifier contracts, resource definitions and finite cases before confirmatory evaluation. No scientific outcome, dollar cost, customer, financial account or commercial qualification is established by this document. Arithmetic unit fixtures are implementation checks, not confirmatory acquisition cases.

The concrete purpose is to obtain an accepted material inference and its different spatial decision under the same frozen quality, nuisance, permission and resource contract. The proposed intervention changes the acquisition operation to address the earlier coherent sample/reference gain ambiguity. Its value must be compared with competent calibration and ordinary use of exactly the same paired observations. The existing five-route portfolios, original artifacts and native accounts remain unchanged.

The deliverable here is a conditional choice frontier and explicit missing-input/refusal reasons. This module neither executes an account nor maintains a transaction ledger. It imports no finance engine, reads no accounts or keys, sends no offer, and grants no spending authority. A later operating simulation, if separately directed, must use the canonical `JournalAccount` and adaptive `Account` with its own prospective registration and complete source binding.

## Choices and common acceptance

The four technical choices are `single_read`, `independent_calibration`, `paired_swap`, and `ordinary_paired_swap`; `non_entry` is always reported separately. The last choice is an independently implemented conventional estimator, including joint least squares when applicable, using the same paired observations and acquisition permissions. It is not forced to retain the inadequate common-gain assumption.

| Choice | Observation operation | Admission condition |
| --- | --- | --- |
| Single/common-reference read | Original sample/reference operation | Must meet the same accuracy and abstention contract in the actual nuisance case; residual fit alone is insufficient |
| Independent calibration | Independently acquired blank/calibration plus sample observations | Calibration uncertainty, validity interval, alignment and acquisition resources are explicit; true gain is not supplied as a free oracle |
| Paired swapping | Sample/reference observations with the declared path interchange | Must satisfy the frozen inter-frame drift, corrected-read error, geometry and resource conditions |
| Ordinary same-observation control | Competent conventional estimator with the identical paired data | Receives the same operations, nuisance bounds and total resources; a tie remains a tie |
| Non-entry | Decline this additional acquisition | Delivers no measurement; zero additional acquisition cash does not erase prior research or quantify the forgone benefit |

Every input document names one registered case and one scientific-contract SHA256 and permission-contract SHA256 that apply to every choice. Scientific verdicts are supplied by the separately frozen evaluator as `accepted`, `refused` or `unresolved`, with a receipt SHA256 for an evaluated verdict. The economic module does not independently establish their truth, change tolerances, drop hard cases, or treat abstentions as delivered measurements. A rejected or failed attempt keeps its consumed-resource/cost report.

The initial corrected-read error and inter-frame log-gain drift bounds are scientific hypotheses, not measured detector noise or calibration. In particular, a deterministic relative-error envelope does not establish a Poisson dose-performance relation. A nominal photon allocation alone cannot make that bridge true.

## Resource accounting and matched budgets

Each choice provides the complete episode vector, not just a favorable individual reading:

| Field | Unit and interpretation |
| --- | --- |
| `light_frames` | Number of illuminated acquisition states, including illuminated blank frames |
| `light_readings` | Number of recorded illuminated detector/path readings; simultaneous readings are not separate frames |
| `dark_frames` | Dedicated dark acquisition states; shared dark calibration is counted once at its actual registered scope |
| `dark_readings` | Recorded dark detector/path readings |
| `blank_frames` | Illuminated calibration states without the specimen; a subset of `light_frames`, not another uncounted source exposure |
| `specimen_exposures` | Illuminated frames in which the specimen is exposed |
| `source_photons` | Declared incident source-photon allocation across all light frames, including blanks |
| `specimen_photons` | Declared allocation incident on the specimen; not automatically equal to source photons or absorbed dose |
| `elapsed_seconds` | Acquisition occupation including required calibration, settling, movement and readout; unknown physical times remain null |
| `swap_operations` | Required physical/path exchanges or equivalent qualified routing operations |

Count fields are nonnegative integers. Photon allocations can be exact nonnegative model means; the contract must identify whether they are assumed or measured. Dark, blank, source and specimen quantities are not interchangeable. The paired and blank-plus-sample alternatives can each use two dual-path light frames and four light readings per energy, while exposing the specimen twice versus once. Those frame counts do not imply equal specimen dose, equal elapsed time, or lower cost. The actual scientific resource record supplies the values; this module assumes none of them.

All choices receive the same resource ceilings. A ceiling is a nonnegative quantity, `null` for unknown, or the explicit string `unbounded` when the registration intentionally imposes no ceiling on that dimension. An unknown ceiling is not unlimited permission. Source-photon and specimen-photon ceilings remain separate. K2 budgets include every ray, energy and required calibration scope. Retained calibration cannot be amortized across an invented customer population or reused beyond its admitted drift interval.

The paired and ordinary same-observation choices must have identical stipulated resource vectors, other episode costs, cost-scope declarations and rights/capacity status. These equal protocol inputs do not establish equal upstream human and AI research effort, a human wage saving or an autonomous industrial operation.

## Prices, complete scope and unknowns

No empirical USD rate is supplied. Each resource has a separately supplied `cash_usd_per_unit` and `opportunity_usd_per_unit`, both initially unknown. `other_cash_cost_usd` and `other_opportunity_cost_usd` cover the remaining episode costs. Numeric inputs require a nonempty `price_basis` describing their measured source or explicitly authored sensitivity status. The code checks arithmetic, not the truth of that provenance.

Cost categories must be disjoint. For example, a per-frame instrument charge cannot be counted again as the same equipment cost in a per-second charge. The blank frame is already a light frame; an additional blank coefficient may cover only an additional non-overlapping calibration burden. An opportunity cost is the value of a displaced feasible use, not an additional cash payment. If that value is already included in a cash rental or provider hurdle, it must not be charged twice.

`complete_episode_cost_scope` may be true only when the declared remaining acquisition episode includes, where applicable: preparation, construction/adaptation, source acquisition and rights, calibration, equipment and consumables, execution, independent verification, failed attempts, retries allowed by the frozen contract, movement/settling, human intervention, included-model/compute resource cost, maintenance, shutdown, support and remaining obligations. Unknown actual bills, model tokens, session resources or upstream work stay unknown. Explicit zero requires evidence or a clearly labeled assumption; it is never the fallback for a missing field. A fully priced finite episode is still not a complete business.

`prior_campaign_cost_usd` remains separately visible and is unknown unless established. A marginal acquisition decision does not pay an already incurred cost twice, but a whole-campaign comparison must retain it. The present module does not produce an amortized per-customer profit figure.

## Frontier and break-even inequalities

For choice i, let q[i,r] denote the resource vector, c[r] a disjoint unit cash cost, w[r] a disjoint unit opportunity cost, K[i] other remaining cash cost and H[i] other opportunity cost:

`Cash[i] = K[i] + sum(q[i,r] * c[r])`

`Opportunity[i] = H[i] + sum(q[i,r] * w[r])`

`EpisodeCost[i] = Cash[i] + Opportunity[i]`.

The resource Pareto frontier contains accepted, budget-feasible choices with fully known resource vectors. It excludes non-entry because non-entry does not deliver the same outcome. It is explicitly conditional on the supplied scientific verdicts; it is not a USD ranking, a physical qualification or a sale. Equal resource vectors remain tied rather than deleting the conventional comparator.

The emitted break-even inequality for i versus j is:

`(K[i]-K[j]) + (H[i]-H[j]) + sum((q[i,r]-q[j,r]) * (c[r]+w[r])) <= 0`.

It is a meaningful alternative-delivery comparison only where both choices satisfy the common scientific and budget contract. A cheaper incorrect single read is not an equivalent accepted product. Missing coefficients or quantities leave the numerical cost difference unknown. Shared quantities cancel only when their scope and unit-price assumptions actually match. The ordinary paired protocol has a stipulated symbolic tie even if absolute USD costs remain unknown; this is a comparator permission, not a measured productivity result.

For example, if the paired and calibrated alternatives have the same total light frames and source photons, those coefficients cancel. Their remaining difference can still include an extra specimen exposure, a swap, fewer blank frames, different elapsed time, specimen-photon allocation, calibration qualification and other episode costs. The full recorded difference, not only the canceled nuisance term, determines break-even.

For any one resource r with positive additional use `delta_q[r]`, and all other signed cost differences collected as D, the conditional ceiling on its combined unit burden is `c[r]+w[r] <= -D/delta_q[r]`. A negative right side means no nonnegative burden can make that choice cheaper under those premises. Unknown D does not justify inserting a favorable threshold.

## Conditional offer/refusal and financing

For the same delivered outcome, an optional hypothesis supplies buyer gross benefit V, adoption burden A, outside-option surplus U0 and provider hurdle h. No values are invented here. A weakly voluntary conditional price interval exists only when:

`EpisodeCost[i] + h <= price <= V - A - U0`.

An empty interval returns `REFUSE`; missing terms or incomplete costs return `HOLD`. The complete conventional alternatives and self-service inform U0; a positive modeled interval is not consent, an equilibrium, a customer, a sent offer or realized profit. Any calculation remains an engineering-acquisition hypothesis. It cannot offer an unqualified physical inspection service or authorize physical actuation.

This interval is conditional on the specified accepted delivery. It is not an expected-profit calculation: physical qualification, default, refund and adoption probabilities are not supplied or estimated from a finite synthetic pass fraction. Risk-bearing participation and sufficient downside funding would require a separate registered contract before a commercial claim.

The finite conservative financing scenario assumes every remaining cash expense is paid before any receipt, no borrowing and no unmodeled refund or future support tail. The separately reported necessary monetary condition is:

`available_cash_usd >= Cash[i] + protected_cash_usd`.

Inputs refer to hypothetical currently available cash after prior expenses, not expected revenue, a conditional invoice or promised investment. Protected cash is not an expense. Opportunity cost enters the economic price floor, not a fictitious cash deduction. Missing complete remaining cash cost, available cash or protection produces an unresolved financing result. Meeting this inequality does not establish rights, equipment availability or technical feasibility. Different payment/credit timing requires a separate supported native-account registration; this module does not add financing flows.

No capitalization frontier, $100,000/$1 billion operating comparison or $3 billion annual-profit result is asserted by an unpriced acquisition calculation. Such capital levels remain possible future separately registered comparisons if a scientifically and commercially specified offering warrants them.

## Execution interface and prospective gate

`economic_frontier.compare(document)` is a pure calculation. The CLI reads one public JSON input and writes JSON to stdout:

```sh
python -m experiments.paired_acquisition_20261102.economic_frontier INPUT.json
```

The input schema is `paired-acquisition/economic-input/v1`. Required top-level inputs are `case_id`, the two contract hashes, `budgets`, `cash_usd_per_unit`, `opportunity_usd_per_unit`, and the four `choices`. Every resource map contains exactly the ten fields above. Each choice contains `method`, `quality`, `quality_receipt_sha256`, `rights_and_capacity`, `resources`, `other_cash_cost_usd`, `other_opportunity_cost_usd`, and boolean `complete_episode_cost_scope`. Rights/capacity is `admitted`, `refused` or `unresolved` for this exact episode, not a blanket license. Optional cash, prior-cost and offer-hypothesis fields default to unknown. All quantities may be exact integer/decimal/rational inputs; unknowns are JSON null. Numerical USD fixtures must be labeled as authored and are not empirical prices.

The output binds the complete input and economic source hashes; keeps resource, cash and opportunity results separate; preserves unknowns and refusal reasons; and has permanent false flags for native-account execution, sent offers, granted authority and commercial-profit qualification.

Before evaluation, root must freeze the scientific verdict interface, measurement denominators, exposure/dose/dark/calibration definitions, price provenance or unknowns, cost scope, budgets, accepted/refused/unresolved handling and stopping rule. No post-result price or resource choice may be represented as this original confirmatory contract. The first expected outcome may be a resource trade-off and unknown dollar frontier; that is a useful decision result, not a failed business hidden by fictitious demand.
