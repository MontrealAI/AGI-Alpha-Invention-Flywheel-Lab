# Out-learned: do not pursue this codec as Super Alpha

**Decision: stop this line as a flagship.** The implementation works, but it does not make a consequential new activity possible.

## Why it failed

Ordinary locally recoverable codes already satisfy the complete service: eight data shards stored as fourteen shards, recovery after any three losses and each specified rack loss. The constructed XOR code averages **3.07** helper reads versus **2.43** for an ordinary pair-local code. Its better worst case, **4 versus 5**, comes with poorer reliability: it fails **8 of 20** fresh rack layouts. That is a tradeoff, not enormous advantage.

Reusing the codec for binary matrix computation demonstrates ordinary linearity, not a successor unavailable to competitors. No paying demand, complete-cost advantage, earned expansion or $3 billion trailing-year profit was established. The $100,000 primary capital challenge was not executed.

## What must change to succeed

- Start with a consequential beneficiary outcome that strong existing alternatives cannot already deliver within the same complete budget.
- Construct the missing means, then compare equivalent reliability, quality and end-to-end cost. A favorable narrow metric is insufficient.
- Establish voluntary demand and economic capture, then show a successor that benefits beyond ordinary equal-content reuse.

Do not continue codec or matrix-repair sweeps as a substitute for that search. No replacement flagship is admitted.

## Compact verification retained

Seven implementations passed 198,240 byte-recovery cases; 5,880 minimum-read repairs and 9,440 successor cases passed. Independent arithmetic and all subset ranks agree. Five unit tests include seven corruption probes. Search-trace, tie-breaking and unequal placement-budget deviations remain disclosed in [independent notes](INDEPENDENT_NOTES.md). These are computational tests, not customers or production qualification.

Source, frozen protocols and losslessly compacted results remain for reproduction; no raw datasets, private accounts or keys are included. No merge, release or physical deployment is claimed.
