# Claim and recommendation corrections

## Characterization cost bound

The twenty-hour shared component is an **assumed nominal-capacity C/20 scenario**, not a measured lower bound for every cell. If C-rate uses nominal capacity, an aged cell's C/20 duration is 20 times actual capacity divided by nominal capacity, before additional shared stages. No dataset measurement durations have been acquired at this stage.

The general conditional bound is exact: ten-to-four anchors save `6A/(F+10A)`, where F is shared burden and A is one anchor's burden. Fifty percent requires `F <= 2A`. At the explicitly assumed F=20 h and A=1.04 h, the saving is 20.5263 percent; common charging, calibration and other costs lower that fraction. The initial half-cost proposal lacks evidence and fails this stated scenario. A universal physical or dollar-cost failure is not established. Frozen fields named `shared_hours_lower_bound` and related names must be read with this correction.
