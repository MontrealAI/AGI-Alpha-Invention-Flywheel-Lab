# Independent evaluator construction

The evaluator was written by a separate included assistant agent before seeing method source or confirmation outcomes. Method builders received `INTERFACE.md`, K1 development observations and equal access to requested development probes. Ground truth and outcome acceptance are evaluator-owned. All agents share a host and conversation coordinator; this is procedural separation, not external blinding, a security sandbox or independent institutional replication.

The simulator is authored synthetic evidence. It implements finite provider effects, holds, key expiry, stale status, compensation refusal, costed sandbox instrumentation and four fault schedules. It does not validate real services, Byzantine actors, indefinite partitions, crashed coordinators or arbitrary event schedules. Its acceptance checker reads actual final state independently of the graph's claimed result. False completion, duplicate effects, abandoned holds and concealed partial effects fail. Truthfully reported unresolved obligations remain costed and cannot earn accepted-outcome payment.

## Pre-freeze correction

During evaluator design review, the fourth schedule originally identified the last provider in the public task list as the one that would refuse. A constructor could exploit this by executing that known provider first. Before confirmation generation, the coordinator and evaluator changed this to a hidden seed-bound refusal target. Both builders were informed before freezing source; K1 singleton observations remain identical. This is an evaluator/developer integrity repair, not a learned treatment improvement. No scored trial was replaced or rerun as a result.

A second pre-freeze check found that an unsupported or unprepared commit could consume the one productive network-fault allowance. The evaluator now applies that allowance to execute or a supported commit with a hold/prior committed effect. A meaningless unsupported call cannot remove a later productive request's challenge. This correction also precedes all confirmation and is not treatment learning.

## Sampling and inference scope

The registered set contains six K2 mechanism-composition families with eight deterministic draws each. K1 development consists of singleton providers. The K2 change is composition plus varied delays, expiring holds and incomplete measurements. Provider primitives partly overlap K1: this is not a wholly unseen operational universe. Report family-level effects and duplicate/normalized-semantic identities; do not treat 48 authored draws as 48 independently sampled real markets. Confirmation source and exact seeds must be frozen before execution. Later reruns are reproductions.

Independent acceptance tests cover fake completion, clean refusal, duplicates, concealed effects, unresolved exposure, failed compensation, request/ack ambiguity, stale status, expiring keys, budget enforcement, private-state exclusion, forbidden fault overrides, inter-provider hold expiry and the hidden refusal target. These tests validate implementation and claim boundaries; they do not establish the business opportunity.
