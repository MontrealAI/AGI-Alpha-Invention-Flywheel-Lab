# Retained optical discovery instrument

This bounded experiment constructs a planar multilayer optical design instrument and tests transfer from a near-infrared antireflection coating to a two-band spectral-routing filter. It compares retained procedure, ordinary equal-content reuse, equal content without a special discovery procedure, and a fresh specialist using an independently implemented scattering kernel. Established methods are deliberately strong competitors; generic optical optimization is not a new industry by itself.

The computational domain is coherent, flat, isotropic room-temperature films on a semi-infinite silica substrate, wavelengths 0.7–1.5 micrometres and incidence up to 45 degrees. MgF2 ordinary-ray data are an approximation for a film, not a physical certification. Separate characteristic-matrix, scattering-recursion and boundary-linear-system calculations check specified Maxwell consistency. Fresnel and quarter-wave limits, input rejection, nonzero material absorption and distribution shifts challenge the instrument.

The prospective scientific contract, seeds, acceptance, finite search and failure rules are in [PREREGISTRATION.json](PREREGISTRATION.json). [SOURCES.md](SOURCES.md) compares three selected domains and separates source facts from missing deployment evidence. [ECONOMIC_INPUTS.json](ECONOMIC_INPUTS.json) records scenario estimates for the coordinator's canonical account; this route does not introduce a ledger.

From repository root:

```bash
python3 experiments/public_portfolio_20261102/foundry/run.py --output /absolute/new/foundry-results
```

NumPy and SciPy are required. Output includes actual layer designs, finite acceptance worlds, source hashes, generic correctness checks, measured CPU/wall use and a frozen K1 manifest. Independent evaluation is performed outside this constructor's directory. A source freeze is chronological preregistration, not an externally blinded physical trial; public downstream task definitions are not secretly represented as measured holdouts.

Numerical acceptance, scientific novelty, physical qualification, capability inheritance, improved discovery, human productivity and commercial profit are separate claims. An ordinary reuse tie must remain a tie. Inheritance is not called qualified if K1 fails; K2 failures are retained. No fabricated device or actual commerce is implied by a successful computation.
