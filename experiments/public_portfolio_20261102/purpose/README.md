# Purpose-preserving safety and active diagnosis

This route constructs a finite, proof-carrying mission controller and then a different function: safe active actuator-fault diagnosis. It is an actual combinatorial instrument, with no device control. The input model is supplied rather than learned or physically calibrated. No current result supports novel robotics, safety certification, a new industry, customer demand or the profit objective.

## What changes and what remains true

The inherited means stores/unrolls trajectory searches and repeatedly reconstructs the same recovery calculation. Change A uses a finite winning-set certificate; change B retains compatible recovery computation. All four factorial arms preserve the exact same universal mission and future-recovery requirement. A goal-only or nominal shortcut is an invalid outcome and is tested as a rejected ablation.

For a safe set S and target G, the certificate uses W0 = S intersect G and W(t+1) = Wt union the safe states with some allowed action whose every modeled successor belongs to Wt. Each accepted action points to the previous layer. Induction establishes bounded reachability in the supplied model. To preserve emergency obligations, mission synthesis restricts every visited state to the separately constructed recovery winning set. The primitive is conventional adversarial dynamic programming; an unrestricted memoized recursive solver is an equal-access comparator.

K2 is not a larger delivery batch. It constructs observation-contingent tests that distinguish latent actuator faults. Its state records the observed physical location/energy and every world still consistent with observations. Actions are common across all remaining worlds, branches are grouped only by available observations, and the policy never reads the actual fault. The reused K1 kernel constructs emergency recovery and safe diagnostic winning sets for this new belief game. There is no borrowed K2 answer cache.
