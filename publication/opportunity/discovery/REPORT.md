## Executed local technical localization

The registered pilot used **eight real English passages** from the published Activation 1.5 Factory report and 1.4 Cascade replay, frozen at `436bb1b142a0da1f2c272f77821b75c3efdd73fe`. Both arms received the same vendor-formatted prompt, real source passages, generation settings and five CPU threads of llama.cpp b12242 through numeric loopback. The primary measured screen required all protected quantities and identities in each complete draft. Additional scientific and editorial acceptance requires semantic review. The experiment did not compare reviewer attention with the incumbent direct writing workflow.

The new model retained `DJF` and `NDJ` and preserved the intent of abstaining for the official operational climate request. The previous same-family control omitted both seasonal identifiers and rendered the actual abstention as a scope-compliance statement. The new model rendered the technical concept of candidate TESS timings as incorrect French, including `horodisques`, and wrote `abstente` in the NOAA draft. Neither raw output qualifies for automatic publication. Run order was old then new with one measurement per arm, so the wall time and memory numbers describe this execution. Weight downloads took 44.88 s for 1,133,080,448 bytes on the old arm and 52.09 s for 1,348,432,160 bytes on the new arm. Both inference routes stayed on local loopback. Operator attention, editing expense and whole-work cost are unknown.

The useful retained mechanism is the versioned **factual-anchor check** with source identity bindings, which can refuse incomplete drafts prior to expensive review. It neither checks all meanings nor admits the new model as a productive replacement. The next decisive localization test gives both versions the same independently established bilingual term list and measures actual first and repeat review effort against an accepted direct translation.
