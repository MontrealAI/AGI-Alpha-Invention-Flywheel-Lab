## Registered scope · 2026-11-24

MONTREAL.AI maintains NOAA Archive Point, which must account for the exact byte window received before interpreting a forecast. The opportunity under test is to move a narrow calculation from repeated model calls into a portable deterministic HARNESS instrument with an independent acceptance path. The incumbent for the acquisition route remains the qualified archive code, with NCAR's point service preferred when applicable. An ordinary Python calculation is the strongest relevant comparison for the proposed arithmetic subtask. This is an engineering qualification on observed public responses. The task does not measure new forecast accuracy, member benefit, or an unserved commercial need.

Other integration opportunities considered were endpoint evidence screening, already handled by indexed SQLite, and historical release recovery, where Zstandard won. Neither justifies another challenger in this release. Byte-window checking has an external exact standard and an existing signed reference, which make it suitable for trying the new construction-to-reuse interface with a distinct acceptance implementation.

- **S₁ task** — For declared integer fields `start` and `end`, each from 0 through 2,000,000,000 inclusive, report exact integer `bytes = end - start + 1` and Boolean `ordered = start <= end`. A false `ordered` means abstain, regardless of `bytes`. Noninteger, missing and out-of-domain inputs are rejected before execution. The training prompt may contain one synthetic three-byte span. Once the candidate JSON is frozen, replay all retained direct partial responses and all corresponding whole-field ranges that recorded exact body bytes, then the distinct standalone receipt as reuse. Include one-byte, reversed, missing, overflow and noninteger controls. Compare the first constructor answer and at most one syntax-only repair. The model sees no archive records or held answers in construction.
- **S₂ task** — Reconcile an observed partial response body to a normalized byte range. Given `start`, `end`, `length` and `body`, all nonnegative integers in the same domain, return Boolean `matches`. It is true exactly when the span is ordered, the last byte is strictly below representation length, and its inclusive byte count equals the observed body count. Status, ETag, encoding and acquisition rights remain upstream requirements. Replay all eligible ranges, change the size by one for a truncated-body control, and include an invalid representation boundary and reversed range. Both arms get the same S₂ contract, no held cases, equal token limits, no tools, same seed and no retries.
