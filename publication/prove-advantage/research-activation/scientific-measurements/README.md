## JWST · conditional recovery from a blended spectrum

For one public JADES GOODS-N galaxy, the PRISM Hα and [N II] blend gave a model-dependent ratio of **0.102** for the stronger [N II] line (6585 Å in vacuum) relative to Hα, after fitting the original Hβ and [O III] region jointly. G395M exposures of the same slit footprints gave **0.083**. The equal-information ordinary physical fit reproduced the result. Withdrawing the extra wavelength region widened the PRISM profile from **0.241 to 1.130 dex**. An independent implementation found the profile widened to **0.921 dex** when modest differential centroid and width allowances were introduced. The profile therefore depends on the shared-response assumption.

Matching individual dither components by celestial slit vertices exposed a sharper failure. One component's conditional PRISM interval was **0.116–0.190** and its separate G395M interval was **0.076–0.107**. The component intervals were disjoint despite narrowly reported PRISM precision. The supplied spectra already have a common wavelength grid per mode. On twelve prospectively selected, distinct GOODS-S systems, the full-window experimental and ordinary methods each accepted zero ratios. [JADES data release](https://jades-survey.github.io/scientists/data.html) · [Paper II](https://doi.org/10.1093/mnras/stag939)

The next qualification should seek a low-resolution measurement whose forward model has **independently measured response variation** across observing conditions, plus separately observed negative controls. For TESS, start with a genuinely full-frame-only source and a resolved independent event before making a strongest-incumbent failure claim. Both open TOI cases remain positive conventional controls. ## Résultats scientifiques

**La qualification du spécialiste scientifique demeure ouverte.** Dans le cas de TOI 1423.01, les observations originales résolues au sol donnent une récurrence de **2,756413176 jours**. La méthode conventionnelle localise la même source dans les pixels TESS et mesure **2,756304288 jours**. Pour TOI 531.01, l’imagerie différentielle des pixels TESS a retrouvé la source de l’éclipse observée séparément au sol. Dans le pilote anonyme, la méthode conventionnelle a mesuré une fréquence TESS compatible avec la référence Kepler dans la tolérance prévue. La méthode par covariance s’est abstenue dans les trois cas. Les trois cas suivants ont également conduit à des abstentions.

Pour un spectre JWST de JADES, l’ajustement de deux régions spectrales a donné un rapport de **0,102** entre la raie [N II] la plus intense (6585 Å dans le vide) et Hα. Les expositions G395M acquises séparément sur la même région ont donné **0,083**. La précision dépend du modèle de réponse commun. Un groupe d’expositions à lui seul a donné des intervalles disjoints dans les deux modes. L’essai sur douze autres systèmes n’a fourni aucun rapport admissible. Les données et les résultats délimitent l’usage de cette méthode. [Résultats et données d’origine](RESULT.json)
