## Frozen comparison

- Input is a hand-authored, source-cited set of strict event precedences. An event denotes effective access for the named actor. Physical delivery alone is insufficient. Visibility from inference, signal-dependent receipt and discretionary nonreceipt are outside this representation.
- Compare reachability with exhaustive enumeration of legal event orders on all 64 forward-edge graphs over four events and all 12 distinct ordered pairs per graph. Require agreement on 768/768 relations. Both paths see the same precedence facts. The enumeration is a separate checking implementation. Ordinary graph reachability is the strongest general deterministic comparator for the same intermediate representation.
- Reuse `order-03`, `pupitre-05` and `cloche-07` from the already-open confirmation panel. Require all 9 access labels to match the frozen reviewed labels with at least one admissible citation per query and no false access claims. These are open, hand-transcribed cases, so the result establishes an interface check. It cannot score raw-language inference or generalization.
- Compare the current reviewed-label control with graph-derived access in the unchanged early, late and unresolved sealed-bid replay. Both arms use the retained `decision_partitions` and game construction. Require identical partitions and exact certified values 1/2 and 1/4, and withhold the unresolved case before calling the solver. Verify numeric values with the separately implemented exact normal-form reference.
- Require rejection of a contradictory event order. Substitute physical envelope receipt for effective access in the authorization-uncertain case. This is a deliberate scope-withdrawal check. Expect one false access claim relative to the reviewed answer, exposing dependence on correct source transcription.

The output is a research receipt with equivalent-or-weaker technical, resource and promotion limits. The hand-off should be independently assessed on fresh, protected raw-language cases only after the authoring/transcription burden can be compared with competent direct use. Stop after execution and preserve all outcomes. Differential checks here share administration. No learner, specialized-model promotion, new solver, independent case custody, or economic claim is in scope.
