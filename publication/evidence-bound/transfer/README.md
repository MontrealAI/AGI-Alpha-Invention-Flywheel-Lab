# Evidence binding on a subsequent release audit

The retained HARNESS evidence mechanism produced **six correct dispositions in six tests** of a fresh release-cache objective. A conventional Python and SQLite witness also scored **6/6**, with much lower execution cost for this audit. The prior released controller and the intervention-withdrawal arm produced no machine verdicts. Both treated their outputs as unverified. This matched intervention and withdrawal establish a reliability contribution to an authored mission. Inventor improvement and recursive compounding remain experimental.

The objective was to determine whether a cache could restore five specific public archives from release #593. Its 3,421,825 bytes were previously captured from the published Pages site. This run checked the exact SHA-256 of each capture, the public deployment receipt and the required release identity. The same inputs were available to all four arms. The separate staging receipt served as an ineligible control. ## Reproduce

Run from the repository with Python 3.11+ on Linux. The replay reads the original `c0a14ba028092db648516718f9127ae8166df63e` source and the same candidate tree from either local `aa42b078e10a745f22f0ce2dba8fceaca8caabba` or public `43d6192655d922d886bceb0b4e61be8bcfaa766e`. The latter’s exact tree is `dab63b5461958e328b11782ca3a11a2a8a9cd5bd`. [Frozen public source](https://github.com/MontrealAI/AGI-Alpha-Invention-Flywheel-Lab/commit/43d6192655d922d886bceb0b4e61be8bcfaa766e) · [Original release source](https://github.com/MontrealAI/AGI-Alpha-Invention-Flywheel-Lab/commit/c0a14ba028092db648516718f9127ae8166df63e)

```sh
python -B publication/evidence-bound/transfer/replay.py --witness /tmp/release-witness.json
python -B publication/evidence-bound/transfer/replay.py --verify-captures /path/to/exact-release-cache
```

The verification command is optional and accepts an existing cache. The mutable historical Pages URL may now serve a different receipt or package revision. Verification requires the captured bytes and refuses a mismatched file.
