# FRONTIER Ω · My Intelligence / Mon intelligence

Start with your ambition in [My Frontier](https://montrealai.github.io/AGI-Alpha-Invention-Flywheel-Lab/frontier-omega-alpha/#my-frontier). My Intelligence can connect an installed local model or a member-controlled API. You can also prepare a reviewed ChatGPT or Codex handoff and bring the work back yourself.

## Launch the companion on this computer

Extract the whole archive. The launchers require [Python 3.11 or newer](https://www.python.org/downloads/).

| System | Start the companion |
| --- | --- |
| Windows | Open `Launch-FRONTIER.cmd`. Keep the command window open. |
| macOS | From the extracted folder in Terminal, run `sh Launch-FRONTIER.command`. |
| Linux | From the extracted folder, run `sh Launch-FRONTIER.sh`. |

Copy the one-use code from the pairing guide into My Intelligence. Keep the companion running. Local setup checks the exact model served by a trusted runtime on this computer. If you need a model runtime, follow the setup link for the engine you select. To use a provider API, follow the companion’s private setup. Review the project and limits before running the paid connection check and review each mission before authorizing it. The API key is entered only in the loopback companion. A ChatGPT subscription is a separate service.

Use **Save mission file** when keeping a private copy before pairing. After a restart, reopen the companion, pair again and select a saved mission. Restore a private mission file if you had saved it before pairing. Review the assisted prompt before copying it to another service. Imported work remains available for review together with its qualification status.

The source revision and hashes of the bundled files are in `manifest.json`. Previous published companion versions can still be downloaded by their versioned URLs.

## Démarrer le compagnon sur cet ordinateur

Commencez avec votre ambition dans [Mon Frontier](https://montrealai.github.io/AGI-Alpha-Invention-Flywheel-Lab/frontier-omega-alpha/fr.html#my-frontier). Mon intelligence peut connecter un modèle local installé ou une API que vous contrôlez. Vous pouvez aussi préparer un mandat assisté pour ChatGPT ou Codex, le relire et rapporter le travail vous-même.

Extrayez l’archive au complet. Les lanceurs exigent [Python 3.11 ou plus récent](https://www.python.org/downloads/).

| Système | Démarrage du compagnon |
| --- | --- |
| Windows | Ouvrez `Launch-FRONTIER.cmd`. Gardez la fenêtre de commande ouverte. |
| macOS | Dans Terminal, depuis le dossier extrait, lancez `sh Launch-FRONTIER.command`. |
| Linux | Depuis le dossier extrait, lancez `sh Launch-FRONTIER.sh`. |

Copiez le code à usage unique du guide de jumelage dans Mon intelligence. Laissez le compagnon ouvert. La configuration locale vérifie le modèle exact servi par un moteur de confiance sur cet ordinateur. Si vous devez en installer un, utilisez le lien de configuration du moteur choisi. Pour utiliser une API, suivez la configuration privée du compagnon. Vérifiez le projet et les limites avant le test payant, puis relisez chaque mission avant de l’autoriser. Saisissez la clé API uniquement dans le compagnon local. L’abonnement ChatGPT est un service distinct.

Utilisez **Enregistrer le fichier de mission** pour garder une copie privée avant le jumelage. Après un redémarrage, rouvrez le compagnon, jumelez-le de nouveau et sélectionnez une mission sauvegardée. Restaurez votre fichier privé si vous l’avez enregistré avant le jumelage. Relisez le mandat assisté avant de le copier dans un autre service. Le travail importé reste disponible pour révision avec son état de qualification.

La révision source et les empreintes des fichiers se trouvent dans `manifest.json`. Les versions précédentes du compagnon restent disponibles à leurs adresses de téléchargement versionnées.
