# Safety correction to preregistered transport

The original fixed protocol remains byte-for-byte unchanged at `2cfd1540af0c056e2648976c9a307d7322ec5685`. A reviewed security constraint governs external artifact transport: **never upload failed raw operating/account recovery files**, even if a script calls an archive `keyfree`. A prior hosted revision had included `failed-keyfree.zip` in an `always()` artifact step. That transport was overly broad. It is withdrawn prospectively in commit `69eed66d7dbfd1980101dbc59e08a4f6eada2ac5` and no historical execution result is reclassified. Only a fully successful source-bound qualification may upload the exported explicitly key-free public ZIP, accepted PROFILE and nonsecret resource telemetry. Failures remain immutable in GitHub Actions steps/logs; the raw private runner state is not exported. The source evidence, accounts and six-hour platform boundary remain unchanged.

This is a **security correction**, not permission to change any scientific stopping rule, resample the registered fixture, weaken the old v1 guard or count source QA as paid commerce. The original signed native business remains inaccessible; P0 original-account migration is still blocked.
