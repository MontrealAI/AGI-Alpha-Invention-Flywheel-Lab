Connected N-0 base and every active single-branch (N-1) outage are the finite scope. Refuse disconnected N-0 cases. For islanding N-1 label `ISLANDING_UNKNOWN`, never `safe`. Do not relabel DC active-power flows as nonlinear AC feasibility, generator rampability, reserve delivery, AC voltage, reactive power or realized safe operation.

Three fixed authored symmetric independent non-slack injection MW boxes for **both** pinned cases:
- Z: all radii zero (must exactly reproduce independent full recomputation of point flows).
- U2: for every non-slack bus index j, radius `0.02 * max(abs(p_mw[j]), 1.0)` MW.
- U10: radius `0.10 * max(abs(p_mw[j]), 1.0)` MW.

The first slack-bus injection is the negative sum of all others for each perturbation. All signs at non-slack buses are permitted simultaneously; there is **no probability, load correlation, generator feasibility, actual reserve availability or observed uncertainty calibration**. A false box has no operational assurance. For each active rated *surviving* branch and each connected base/outage, independently compare candidate maximum absolute MW `max_{delta in box}|f_branch(delta)|` against two signed SciPy HiGHS LP solves using the full independent DC equality constraints. No optimizing only one desired line or cherry-picking outages. LP is an ordinary competent alternative.

## Fixed technical acceptance and stopping

Run exactly two case files × three boxes = six case-box arms, with all N-0 + eligible N-1 contingencies. Every computed connected/rated line must have finite maximum, a declared attaining signed box-vertex witness, and reproducibility within **1e-5 MW absolute** against independently solved LP. Witness must obey each box bound, satisfy the signed network equations within **1e-8 per-unit**, and attain the claimed absolute line flow within **1e-5 MW**. Every connected/no-rated case reports `UNRATED_NO_COMPLETE_CERTIFICATE`; an overloaded case returns `MODEL_UNSAFE` with a witness, never silently claims safe. The only model-safe state is `DC_BOX_N1_WITHIN_DECLARED_RATED_LIMITS` with **no** islanding, all active surviving branch limits rated, and every complete N-0/N-1 bound within declared limits. If some cases are over limit this is an observed unsafe result, not a correctness failure or reason to change the cases.

Adversarial synthetic tests must reject invalid schema, nonfinite radii, negative radii, disconnected base, unsupported/ill-conditioned DC solver, zero/unknown branch rating safety, and must preserve nonempty honest outage/witness outcomes.
