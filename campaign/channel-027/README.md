# Native channel menu — wiring qualification

This opt-in implementation connects existing pilot/extended supplier contracts to the native joint decision and paid exposure path. It removes the blanket prohibition on new contracts while any tranche is live, but preserves each supplier’s tranche cap, actual contact fatigue/cooldown, overlap, expiry, and native earned-funds authorization. More configured prospects are not free reach or sales.

Forecasts use declared conversion uncertainty, observed margins, bounded remaining contacts and current capacity. Overlapping future reach is not counted repeatedly. Same-day expansion benefit sharing remains conservative: unverified complementary channel-plus-capacity or two-channel gains cannot simply be added. This is an exact choice over the declared finite options, not a global long-horizon optimum.

The public channel027 workflow reproduces an exposed 14-day, 36-prospect engineering fixture (seed/cohort 2610311751) and independently audits native execution. The prior local run actually paid for two overlapping pilot tranches using earned funds, then obtained paid exposures and settled linked deliveries. Extended is available and checked, but that run did not choose it. This is not a matched commercial improvement or fresh scaling confirmation.

Only compact public SUMMARY.json is uploaded. Actual private accounts, keys, and raw logs stay out of publication. Complete production costs use the reviewed common-cost contract; fixture economics remain authored rather than measured host/model bills.

A larger reachable-demand comparison is a distinct pending experiment. Financial-package selection awaits the fixed capital025 evidence; no 112-day/96-prospect scaling outcome is claimed here. Bundles and higher-priced portfolio services are not silently added without work-key, capacity, quality and equivalent-workload validation.
