## Integration recommendation

Reuse existing exchange via its actual validator/checker interface only if the selected delivered artifact needs simulated exchange; test both ends with real task/output bytes. Reuse exact evidence contracts for bound objections if their scope fits. For generated programs, use a qualified actual effect sandbox and preserve old cutoffs/source controls. A new lab campaign allocation does not replenish prior spent resources or confirmation alpha. For a bottleneck outside existing registered families, publish the mismatch and construct only the necessary adapter; do not label a new small fixed menu a stronger invention engine. Keep foundation changes out of the first lab cycle unless their native interface is actually exercised.

No current finding establishes consequential enabling change, complete commercial viability, independent demand, unrestricted earned funding, causal successor benefit or the connected flywheel. The existing negative evidence constrains those claims.
