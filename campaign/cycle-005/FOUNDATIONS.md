## Necessary domain construction

`mechanisms/construct.py` is a simpler, independently authored constructor for
the present typed event DAG. It replaces cycle 004's factorial permutation search
and literal initialization-repair operator in a new namespace. Original source
and original evidence are unchanged. This is a domain-specific replacement,
not a claim that the small constructor supersedes Omega generally.

`construct(task, obligations, max_candidates, operator)` first derives a
topological execution order. Transferred or adjudicated obligations drive typed
rewrites that add exact failure scopes, atomic-publication scopes and causal
resource compensations. Local rewrites, predecessor closures and complementary
bundles construct combinations determined by the graph and constraints, rather
than selecting one of a supplied list of complete workflows. The bounded
best-first frontier records every evaluated candidate and its violations.
Inherited `event-plan-rewrite/v1` rules match actual phase types/units and optional
mapping-bound phase selectors; they generate obligations on fresh event IDs.

The grammar permits at most 48 phases and 48 obligation records, three rewrite
kinds and at most 256 evaluated candidates. It does not invent new primitives,
execute arbitrary code or change its external useful-objective checker. Its
logical cost counts program structure and is not monetary cost. Full process
measurements belong in the cycle resource receipt.

`interpret` executes these programs as inert data inside the existing qualified
seccomp worker. Trusted actual-effect execution must consume the same program
and match its receipt semantics. A simulated interpreter pass alone is not
actual filesystem failure-atomicity. `conventional(task)` protects all phases,+makes commit publication atomic and compensates causal reservations; it remains
eligible to match or beat the constructed plan under the same external spec.

Eight engineering tests exercise mapped obligation intervention, complementary
scope/publication removal, a 30-phase shuffled/renamed graph, operator
instantiation, compensation causality, malformed graphs/units, explicit search
exhaustion, the conventional comparator and actual seccomp interpretation.
The first run exposed a search-priority defect: cheap single repairs could defer
an available complementary bundle beyond a small candidate allocation. The
priority now includes the remaining obligation count and prefers fewer remaining
violations on ties; the unchanged 30-phase bound test then passes. This exposed
engineering test is development evidence, not protected scientific confirmation.

Alpha's small pinned structural-record adapter continues to execute identity,
bounded record creation and exact acceptance-binding functions. Its source pin
and tests are unchanged. These controls establish artifact identity and tested
protocol behavior; demand, scientific superiority and complete-cost commercial
compounding remain separate outcomes.

## Objective-preserving reframing and search-policy controls

The pre-freeze extension adds `reframe` and `evaluate_policy` inside the same
constructor module, not another architecture. Eleven constructor tests now pass.

`reframe` keeps the exact objective hash over source identities, complete check
identifiers, service obligations and safety obligations. Git history is recorded
separately as an implementation assumption. A verified source snapshot is an
alternative dependency-provenance representation only when that capability is
present and an external receipt binds the same objective, exact sources and all
required checks. Merely naming a snapshot capability does not admit it. This
does not recreate unavailable historical ancestry or waive portable execution.

`evaluate_policy` crosses old/new search policy with old/new starting primitive
sets. Both policies receive identical typed tasks, obligations and candidate
allowances. The old tool set contains failure protection; the new set additionally
permits atomic publication. Unavailable obligations are retained in the trace,
not silently marked satisfied. The function supplies construction only; the
unchanged external verifier grades every cell and the conventional control.

For at most seven phases, the old arm executes actual unchanged
`flywheel/strategy.py:synthesize` through bijective phase aliases. Its pinned
source SHA-256 is
`93b00697efbbdb2e29c357ee83f30e46ac220068783731568c297f0017453b17`.
For larger admitted event graphs, the actual old `permutations` generator and
guard enumeration run under the shared typed event-plan adapter. This extends
the original engine's representation limit: it is explicitly an adapted search
policy comparison, not a claim that original `synthesize` accepts eight phases.
Missing source, unknown tools or unrepresentable input is refusal/unknown,
never fabricated performance evidence. The same additional primitive adapter is
available to both policies in each crossed cell.

Each result records candidate attempts, unavailable obligations, source/adapter
identity and measured wall/CPU time. These measurements are marginal policy-run
costs; acquisition, development, integration and verification remain separately
charged. The new policy is developer-authored in response to exposed engineering
defects. A better result would establish a bounded software-engineering policy
improvement, not that the discovery policy autonomously learned or generally
improves invention. This distinction separates changed search behavior from
improved starting tools and retained content.
