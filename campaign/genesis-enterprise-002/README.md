# ALPHA GENESIS FLYWHEEL Ω — operating increment 002

**See the frontier. Discover the consequence. Deliver what is worth building.**

This opt-in increment connects a qualified computational delivery to the existing
`JournalAccount` / mandatory adaptive `Account`. It does not start another money
ledger, migrate old balances or replace the existing enterprise entry point.
It extends PR #229's frontier-to-possibility work.

## What is implemented

- Public GitHub release observations with source identities, actual publication
  and observation times, deduplication, and explicit unverified access. On demand,
  not an already running global monitor.
- An optional installed Codex proposer restricted to the user's existing ChatGPT
  login: no API-key fallback, no login creation, no purchases. It generates at
  least three new construction hypotheses, not options from a fixed industry
  catalogue. Returned ideas cannot approve themselves or execute code.
- An exact finite posted-price controller that can prefer an ordinary solver,
  a newly qualified outside capability, or no entry. A maintained inherited route
  receives no preference. Prices and buyer choices are scenario assumptions.
- A recoverable native operating sequence: development and acquisition costs,
  voluntary modeled choice, funded order, native resource commitment, actual
  production, independent acceptance, collection/refund, obligations, tax scenario,
  and later deliveries financed only from unrestricted earned funds.
- A fixed-sample paired-campaign comparison helper. It can reject unsupported
  discovery-policy improvement; it does not learn or establish an improved inventor.

## One command to execute the operating pilot

From a checkout containing this increment, Python 3.12 with the repository's
commercial dependencies and NumPy/SciPy:

```sh
python -m pip install -r requirements-commercial010.txt numpy==2.3.5 scipy==1.17.0
python -m connected_enterprise.genesis pilot --output /absolute/new/genesis002
```

Open `/absolute/new/genesis002/public/index.html`. The report distinguishes
actual computational artifacts from **simulated** buyers, collections and costs.
The first installed delivery adapter uses the existing `flexibility063` planning
instrument. This ordinary service is an integration test, **not the Blue Sky
flagship**, new physical energy service or a new scientific discovery.

The separate stages are available for pause/recovery:

```sh
python -m connected_enterprise.genesis register --output /absolute/new/genesis002
python -m connected_enterprise.genesis operate --output /absolute/new/genesis002 --max-steps 3
python -m connected_enterprise.genesis resume --output /absolute/new/genesis002
python -m connected_enterprise.genesis audit --output /absolute/new/genesis002
python -m connected_enterprise.genesis export --output /absolute/new/genesis002 --destination /absolute/new/genesis002-public
```

Create `STOP` in the workspace to pause before the next operating stage; remove
it to resume. Reopening preserves the original account and signed state. An
export is key-free and auditable, but cannot take over the original account.
If an interruption committed a cost before its phase checkpoint was saved,
STOP preserves that unreconciled state and audit fails closed. Remove STOP to
replay the same deterministic phase without duplicating the expense.
Never publish `private/`, simulation signing keys or a full working directory.

## Frozen comparison and cost basis

`PROTOCOL.json` registers one finite fresh simulation before execution. Initial
capital is a scenario variable, not a new enterprise-wide capital limit. Four
existing task profiles are independent delivery requests, not four independent
invention campaigns. Costs include stated development/search, all acquisition
attempts, period maintenance, prepaid production/checking, fees and a stated tax
provision. Actual host/model bills, real demand and real wages remain unknown;
no mandatory fictional human labor is inserted.

The strong ordinary solver is available with the same task and constraints. The
native audit checks actual delivered artifacts, complete recorded costs, the
finite optimal choice, collections and earned-only continuation. Ordinary
technical ties are retained. They do not veto conventional commerce, but cannot
be described as invention superiority or causal successor improvement.

## Three consequential tracks — none pre-approved

1. **Purpose-built scientific observation.** Construct a new observation that
   separates a consequential physical ambiguity. Compare complete sensing and
   inverse-method alternatives, then require actual measurements and buyer evidence.
2. **New productive industrial cooperation.** Construct a missing physical process,
   interface or voluntary operating arrangement that opens a valuable activity.
   Existing aggregation alone does not qualify; all participant alternatives count.
3. **Executable research-to-production methods.** Convert an applicable newly
   supported scientific method into a useful tool, with complete benchmarks against
   existing software and unrestricted frontier agents. A theorem is not a product.

All three need external opportunity evidence and a decisive enabling construction.
The operating pilot removes a funding/delivery/recovery dependency of those
campaigns; it does not replace their scientific and commercial tests.

## Funding and dated-maturity correction

The original `0964ad2` hosted pilot failed six native tests before completing its
operating comparison. The second quote ignored the first order's still-retained
full exposure: the operator had only processed maturities at final completion.
The selector also omitted the upfront fee and full custody collateral from its
cash-before-production check. Those original failures remain failures.

The corrected operator invokes the existing canonical maturity operation at each
job's registered hour, before overhead and selection. It never matures at or before
the inclusive claim boundary, shortens terms, removes residual claims, adds cash,
or rewrites a historical account. A quote must leave enough available cash for its
fee, full-price collateral and production, as well as the registered reserve.
Non-seed production must also have earned funds covering the fee and production.
Unfundable quotes are excluded; a lower feasible quote or no entry can win.
Native-ineligible prices and residual terms are rejected during registration.

Regression coverage includes exact cash/earned boundaries, buyer refusal/no entry,
same-hour maturity reconstruction with zero overhead, and interruption recovery.
Both GENESIS workflows use the existing standard runner, six-hour platform window
and first-step job clock. See [repair qualification](FUNDING_REPAIR.md) for source,
local evidence, dependency differences and the remaining hosted review gate.
