# KTC natural-workload residual test — preregistration

Registered 3 November 2026 before reading evaluation measurements or ground-truth arrays. Public leaderboard/paper descriptions are previously visible, so this is a held-out-from-current-construction reproduction, not a historically unseen benchmark.

Purpose: determine whether released conventional code already supplies usable interior-shape reconstruction on real physical measurements, and whether the next missing means is production, missing observations or qualification. This test is deliberately separate from the qualified Omega source, protocols and accounts. No physical intervention or commercial demand claim is possible.

Sources fixed before outcomes: corrected KTC 2023 Zenodo v3, DOI 10.5281/zenodo.10986692; official Codes_Python.zip, EvaluationData.zip, EvaluationData_full.zip. Verify published MD5, record SHA-256. Do not use the older distorted ground truths. The released organizer baseline is linearized difference imaging followed by Otsu segmentation. Inspect and execute its actual finite-element code with only necessary compatibility/CLI adaptations; preserve original bytes and log every change. Select deterministic evaluation phantoms A at difficulty levels 1, 4 and 7 (three cases total), without inspecting values or selecting on results. If archive naming differs, map level and A literally and retain the mapping; never substitute a better case.

Primary comparison: same released reconstruction procedure applied to the official limited observation set versus corresponding released full observations on the same three physical phantoms. The full-information comparator is intentionally given additional measured information; it diagnoses an observation constraint and is not an equal-information algorithm-superiority comparison. Record independent official scoring where runnable, per-class binary overlap/area errors, finite output validation, elapsed CPU/wall time, source identities and raw data hashes. Ground truth is available only to the scoring phase; no tuning from these three cases. If official metric cannot run unchanged, mark it unavailable and label substitute metrics exactly.

Decision rule: report all per-case scores, never only their average. If full observations improve all three cases, treat better observation coverage as a supported candidate dependency for a fresh experimental-interface study, conditional on this reconstruction method. A tie or any loss rejects that universal diagnostic hypothesis. Either outcome leaves superiority over capable stronger reconstruction unknown until those algorithms execute at matched information and budgets. Zero-image and exact-ground-truth score checks verify scoring direction and identity only; they are not competent competitors.

Strong alternatives inspection: record availability and requirements for released CUQI-DTU algorithms and submitted ABC/DIP or PnP methods. Check installed dependency environments before declaring any unavailable. Do not install a GPU, buy compute, call paid APIs or claim a weak baseline is the strongest. Extra baseline runs beyond the registered six reconstructions may be reported as exploratory only.

Finite stopping rule: exactly six planned baseline reconstructions (three limited/full pairs), no hyperparameter search, repeated retries only for diagnosed execution defects. Resource or source-access interruption yields an incomplete result with last completed checkpoint; no failed case may silently disappear. Cache source-dependent forward matrices only if mathematical equivalence is validated and caching is equally available in compared runs. This is a finite diagnostic, not a universal platform or business ceiling.

Costs: actual execution work/time and external-data bytes are measured. Developer/model/host monetary costs, human-specialist fully loaded costs, market willingness to pay and physical sensing/qualification costs are unknown. No CPU-to-human labor conversion, invented demand, native financial posting or revenue claim. Retain a compact source manifest, exact runner and outcomes; downloaded datasets remain scratch inputs referenced by pinned public URLs.
