The saved source SHA-256 identifies bytes returned **at observation time**. Neither a source hash nor the issuer's claimed last-modified date establishes historical content integrity, digital signature, copyright license, legal scope or real-world accuracy.

To make the preregistered public observation **once**, from an environment with outbound public HTTPS access:

The command returns nonzero if any registered public source is missing, blocked, unverifiable, outside the source contract, or fails even one frozen passage. The result is retained regardless, including failed pages and measured process CPU/wall. Do not re-run with changed sources or omit failures to manufacture a PASS. Do not set output to an existing receipt: overwrites are rejected.
