# ALPHA GENESIS: from proposed route to accepted local execution

This additive offline bridge closes a concrete foundry dependency: planner labels now lead to actual source-pinned construction/analysis, independent acceptance, a typed reusable method and fresh execution. Public metadata does **not** activate capability. A real local canary does. The planner and numerical instrument remain byte-identical to their separately owned source commits.

## Run

From repository root, Python 3.11+ on Linux, standard library only:

    PYTHONDONTWRITEBYTECODE=1 python -B -m unittest research.genesis_bridge.test_bridge -v
    PYTHONDONTWRITEBYTECODE=1 python -B -m research.genesis_bridge demo --out /absolute/new/bridge-result

The output path must not exist. SUMMARY.json gives the fixed comparison and claim boundaries. Each step has request.json, execution.json and acceptance.json. The canary's synthetic truth is not passed to the adapter subprocess. Retention stores a method descriptor, not a cached result. Fresh successors rerun the actual method against new inputs and acceptance fixtures.

The generic `run --request FILE --fixture FILE --out NEW_DIR` and `audit --request FILE --fixture FILE --execution FILE` subcommands use the same bound acceptance path. Acceptance is restricted to the exact locked fixture tasks/truths (including the registered missing-sense variant), not caller-invented truths or proof of physical truth. New tasks require a separately reviewed fixture/source registration. For portable audit on a different interpreter, reproduce the experiment there: recorded runtime identity is intentionally bound, rather than silently attesting an unavailable binary.

## What connects

1. An unchanged public source observation records URL, exact UTF-8 response hash, observation time, unknown publication time and UNVERIFIED access.
2. The frozen local canary is executed and independently checked. Only that verified local capability initializes the untouched finite planner. No release event grants permission, code or capability.
3. The proposed compile/analyze route executes static trusted adapters. A label alone never promotes an output capability. Missing observations produce ABSTAIN.
4. Supplying the missing sense observations reopens the exact same numerical context; changing calibration/nuisance context does not qualify as replay.
5. Accepted method provenance is revalidated before fresh-instance reuse. Equal-content ordinary invocation and an independently implemented direct solver receive the same new observations.

## Scope and limits

Developer-authored conventional Kelvin/current-reversal construction, synthetic homogeneous non-medical resistive rods, same output class across successors. No arbitrary shell, downloaded code, installs, secrets, paid APIs, external action, ledger, customer or hardware actuation. This is a trusted-local adapter harness, not an adversarial filesystem/code sandbox. Source hashes provide integrity against divergence under a trusted lock; they are not signatures or protection against someone rewriting both code and lock.

The planner's zero search weights express reachability only. They are not free production or complete cost estimates. CPU, elapsed time and Linux RSS are measured, while development, model billing, host dollars, maintenance and total economic cost remain unknown. An accepted artifact is not revenue, a reusable tool is not improved discovery, and this bridge is not yet a self-sustaining enterprise.
