# 🌌♾️ GENESIS Turn 001 — one independently inspectable *simulated* cycle

First product: reconcile a synthetic small-business invoice/payment export, produce a real executable artifact and check it independently against the exact source and incumbent reference.

First economic step: let a **simulated** buyer decline or purchase an offered $65 outcome; post actual native **simulation** order events and all declared costs, check delivery and settle only when accepted.

Different successor: spend $18 from canonical **unrestricted simulated earnings**, then construct and independently check a shared-storage feasibility plan for a fictional clinic and library. The learned/retained method is conservative source preservation, exact units, and independent checking; this is not autonomously discovered knowledge or a proven discovery advantage.

## Reproduce on this repository revision

Requires Python 3.12 and local POSIX filesystem, with new output directories. From the repository root:

```sh
python3 -m pip install -r requirements-omega-mechanisms-v3.txt
python3 -m unittest campaign.genesis_turn001.test_turn -v
python3 -m campaign.genesis_turn001.native_turn run --output /absolute/new/turn-central
python3 -m campaign.genesis_turn001.native_turn audit --output /absolute/new/turn-central
python3 -m campaign.genesis_turn001.native_turn run --stress no_demand --output /absolute/new/turn-no-demand
python3 -m campaign.genesis_turn001.native_turn audit --output /absolute/new/turn-no-demand
python3 -m campaign.genesis_turn001.native_turn run --stress failed_acceptance --output /absolute/new/turn-failed
python3 -m campaign.genesis_turn001.native_turn audit --output /absolute/new/turn-failed
```

**Keep private simulation keys/journal/account state local.** The Actions workflow retains only public-safe REPORT.json summaries, not account recovery authority.

Expected **authored-model arithmetic**, if the real executable checks accept: $65.00 simulated receipts – $12.00 setup – $9.00 production – $2.00 fee – $5.00 verification – $4.00 maintenance – $6.60 modeled tax = **$26.40** pre-successor modeled earnings. The $18.00 earned-funded successor leaves **$8.40** modeled net. Opening $500 simulated seed is not earnings. Unmeasured real developer/model/compute/host/acquisition/marketing/legal/support/hardware costs are unknown and not silently assumed zero.

The first problem's standard producer and the successor's exhaustive optimizer are **ordinary competent engineering**, not proprietary novelty. The second product is only a *numerical* candidate for building-level backup; its fictional inputs cannot certify retired EV batteries or create a viable real microgrid. A stronger no-inheritance competitor may independently reconstruct the same methods. The current experiment shows a simulated cash sequence under an earned-only policy, not a unique causal technological advantage.

For a **real** complete flywheel turn, we must still obtain a verified paying customer, an actual accepted commercial delivery, actual complete costs, and an economically accepted different successor opportunity, then compare inheritance against the strongest feasible complete alternative. Those conditions remain unestablished.
