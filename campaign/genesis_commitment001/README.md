# GENESIS Commitment 001

An opt-in, source-bound **simulated** operating turn using the existing native financial account. It executes synthetic SQLite restoration and a different schema-migration deliverable; independent acceptance reads the actual database outputs. Shared delivery capacity is committed before a promise. A successor is eligible only after sufficient unrestricted earnings have collected.

This is ordinary database engineering and a finite authored commercial model. Buyer willingness, supplier commitments, prices, complete-cost envelopes and timing are assumptions. The favorable price case is not evidence that a three-record restore is worth its modeled price. The cheap self-service case challenges that assumption. Actual revenue is zero. Real demand, production recovery, independently improved invention and the US$3 billion trailing-year objective remain unestablished.

## Reproduce

Use Python 3.12 and a local POSIX filesystem. From the exact source root:

```sh
python -m pip install -r requirements-commercial010.txt
python -m unittest campaign.genesis_commitment001.test_delivery campaign.genesis_commitment001.test_native -v
python -m campaign.genesis_commitment001.runner run --output /absolute/new/commitment-central --scenario central --arm retained
python -m campaign.genesis_commitment001.runner audit --output /absolute/new/commitment-central
python -m campaign.genesis_commitment001.runner resume --output /absolute/new/commitment-central --scenario central --arm retained
python -m campaign.genesis_commitment001.runner package --output /absolute/new/commitment-central --archive /absolute/new/commitment-public.zip
```

Run all `scenarios` and `arms` declared in [PROTOCOL.json](PROTOCOL.json), using a new output directory for each independently funded counterfactual. Never combine their profits or reseed a continuing account. `direct` receives the same information, ordinary reuse and acceptance; it is a strong conventional implementation, not a measured human productivity study.

After extracting the public package, audit from its `source/` directory using the extracted package root as `--output`. The public package has no private recovery authority. Keep the complete original operating directory privately if continuation is needed. Resume must use the original frozen source and identity; changing source is a new experiment, never permission to rewrite past accounts.

## Evidence boundaries

[Protocol and threat model](PROTOCOL.md) · [opportunities and primary sources](OPPORTUNITIES.md).

Accounting uses exact integer micro-USD, immediate expense recognition for modeled development and prepaid delivery resources, and native payment/reserve/obligation records. Seed, collections, recognized revenue, earned available cash and accounting profit remain separate. Unknown actual bills are not assigned zero. No short result is annualized.

The capacity boundary is one owned simulated supplier inventory within one local account. It cannot prevent a real supplier promising its capacity elsewhere. The checker verifies final database contents and integrity, not real-world incident history or a production recovery-time guarantee. No external application, service, customer or payment is touched.

Research application: [Invent the Economy](../../docs/research/invent-the-economy-202610.pdf), pp. 2–3, motivates joint production/commitment/financing with separate acceptance gates; [Transformational Intelligence](../../docs/research/transformational-intelligence-202610.pdf), pp. 1–3, motivates changing the individual-plan formulation while preserving the beneficiary outcome. The implemented mechanism is source-bound shared capacity and native financing, not evidence that those papers' broader objectives have been achieved.
