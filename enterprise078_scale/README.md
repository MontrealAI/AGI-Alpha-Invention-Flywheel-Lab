## What has actually been constructed

An event-driven operator connects costed acquisition, overlapping channels, finite buyer wallets, voluntary outside-option choice, prospective offers, paid production, actual independently checked preparation/characterization artifacts, delayed collection, support, modeled tax, protected reserves, earned-funded K2 construction and capacity leases with activation delays. Each accepted request creates its own output through the original Enterprise078 delivery path. These are useful **finite-model conformance fixtures**, not commissioned physical-laboratory outputs or market-qualified products. The scientific and commercial gap is not closed by an accepted fixture.

Every financial mutation uses the original `JournalAccount` / adaptive account / native exchange. `account.py` merely enables the existing native prefix verifier for the Enterprise078 schema, already supported by `commercial.ledger._NativePrefixReplay`. It adds no balances or financial transition. All sources, complete prefix bytes, prepared artifacts, proofs, ownership and derived fields are rebound. Public final audits still perform full-history replay. This is an engineering optimization, not a learned discovery procedure.

The signed operating checkpoint includes the live queue, buyer commitments, active and pending leases, orders, retained capability, source identities and pending exact command. A crash after a native commit but before acknowledgment replays the same idempotent command. Missing private authority, changed source, an unexplained native append or an existing run without explicit resume is rejected. Reopening verifies the unchanged account and nonempty operating state. Public exports deliberately cannot resume a private account.

## Scope of the annual test

Each case is a **fresh registered counterfactual account**, never a reset, replacement, or continuation of the original PR174 account. Its unavailable original signing state remains a blocker to authentic original-account continuation. Cases and their profits are never pooled. The common simulated interval is **2026-11-03 00:00 UTC to 2027-11-03 00:00 UTC**, exclusive endpoint. This is simulated time, not a claim that a real operating year elapsed overnight.

Opening capital is the smallest declared menu amount covering the initial complete commitment and protected operating needs; $100,000 is a separate reference case. All equity is hypothetical. No new debt operations or copied-balance financing wrapper is introduced. Capital purchases are immediately expensed, principal is not revenue, and an 8% opportunity charge is reported separately rather than counted twice as cash expense.

The 18-buyer / 72-opportunity workload is a finite conformance experiment, **not an addressable-market estimate, permanent scale ceiling, or path to $3 billion**. Enlarging that number is not a commercial construction. Stronger scale claims require credible reachable demand, competitive buyer value, deployable acceptance contracts, paid supply, and a validated native-to-aggregate bridge. Current scalar amounts are explicit authored envelopes. Actual host/model/whole-development billing, actual demand and actual willingness to pay remain unknown, not zero. Native record aggregation does not validate forward extrapolation.

The pricing policy uses current public competing offers and a fixed quote menu. A rival reacts with a one-period lag to earlier published quotes; future quotes and private valuations are not policy inputs. This is an ordinary heuristic, not game-theoretic optimality. Synthetic budget, need and value draws are public reproducible fixtures, not securely hidden holdouts. The native resource API's positive `expected_net` field is a declared planning input, not calibrated expected profit or spending authority; only available native funds authorize spending.

## Reproduce and continue correctly

From the repository root:

```sh
python -m unittest enterprise078_scale.test_scale -v
python -m enterprise078_scale.run --output /tmp/enterprise078-annual
```

One world:

```sh
python -m enterprise078_scale.run --output /tmp/enterprise078-central --world central
```

Resume **that same** intact working directory:

```sh
python -m enterprise078_scale.run --output /tmp/enterprise078-central --resume --world central
```

For read-only public reproduction, extract a key-free evidence archive, enter its `source` directory, and run:

```sh
python -m enterprise078_scale.review ../public/central
```

The reviewer independently invokes native full-history and original artifact acceptance checks, then reproduces the entire operating queue from the declared protocol and binds every non-maturity journal request to a paid operating command. It checks native time, full-year coverage, modeled cost reconciliation, output identity, source identity and the no-pooling claim. Controller replay is same-source reproduction, not independent external authorship or empirical confirmation.

`--max-events` on the low-level operator is an interruption/recovery quantum, not a claim that a partial year is a completed year or a recurring approval gate. Keep its private account and signed checkpoint together. Do not upload `private/`, simulation keys or signing authority to GitHub. The public ZIP is allowlisted to source, native exports, outputs and reports only.
