# CAPABILITY FORGE Ω · first registered experiment

Three candidates were considered. Exact recovery of a measured quantity despite a failed telemetry channel allows an executable test of both a useful conclusion and warranted abstention. Symbolic discovery of invariants in reaction-free transport equations also permits exact checking, but a known nullspace routine closely matches the initial contract. Reconstructing a missing scientific array decoder from public archives has larger format and acquisition confounds and overlaps existing IGNITION work. The first experiment selects telemetry for the clean causal comparison. A conventional tie keeps it a research increment.

## What the system must deliver

For integer matrix `A`, integer measurements `y`, integer contrast `t`, and fault allowance `k`, consider every rational state `x` for which at least `len(y) - k` rows of `A x` agree exactly with `y`. Return an exact conclusion about `t · x`:

- `inconsistent` if there is no such state.
- `determined` with its reduced rational value if all such states agree.
- `ambiguous` if two compatible states give different values.

An exact result includes no assumption about the probability or source of a faulty reading. Use synthetic signed measurements, dependence and redundancy. Physical calibration, measurement noise and field performance need other evidence.

## Data and freeze

- Development uses eight fixed examples drawn two each from four families: redundant observations with a recoverable contrast, a free latent direction, competing fault explanations, and incompatible readings. Intended family is a coverage tag only. An exact verifier adjudicates every instance.
- Before construction, generate sealed qualification and successor cohorts with separate unpredictable seeds of at least 128 bits. Commit their byte digests in the study checkpoint. Neither cohort, digests nor expected answers are included in the builder or diagnostician prompts.
- Qualification consists of 24 cases, six per family, with zero or one permitted faulty reading and up to five latent dimensions. Successor consists of 16 cases, four per family, with different signed matrices and row orders, up to seven latent dimensions and up to two permitted faults. Check every registered case. The builder learns only from development. Once selected, freeze the candidate digest before evaluating qualification; failed qualification terminates the trial without holdout-informed repair.
- The evaluator is authored independently of all model-produced source. It determines consistency by exact augmented rank and estimability/value by an exact row-space certificate. The conventional comparator independently enumerates admissible fault subsets and computes exact affine solution images using FLINT rational row reduction. A verifier/comparator disagreement makes that run inconclusive. No physical validation or independent human replication is presumed.

Missing arms or budget levels remain explicit. Report external human setup and independent-tool coding as study work, separately from the engine's calls.

A technical admission requires 24/24 qualification and 16/16 fresh successor checks with the same artifact. A significant accuracy improvement over a registered comparator requires a positive paired exact McNemar test at two-sided 0.05 on qualification. Compare against both A and B. If F or B completes the same outcome, report the tie or measured efficiency difference and the complete cost tradeoff. Demonstrating a portable, retained tool can be useful independently of superiority. Use the same bytes in the equal-content ordinary reuse control and compare against a fresh construction if measured. A tie with ordinary reuse does not establish improved discovery. Frontier parity requires E. Economics are a separate claim.

## Français

Cette première expérience demande si une grandeur calculée à partir de mesures linéaires reste déterminée lorsqu’un instrument peut donner une lecture erronée. Le résultat doit être exact, ambigu ou incompatible. Huit cas servent au développement. Les 24 cas de qualification et les 16 cas de transfert restent séparés de la construction. Un vérificateur rationnel indépendant du code généré contrôle toutes les réponses. Le comparateur conventionnel utilise FLINT. Le moteur conserve les essais infructueux, les coûts mesurés et les limites, y compris l’absence éventuelle de référence de pointe.
