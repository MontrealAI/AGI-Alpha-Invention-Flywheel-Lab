Your first useful result

Start with the working demo.

  1. Open the HARNESS and choose Explore the working demo.
  2. Read the synthetic mission and its declared assumptions.
  3. Choose Run the experiment. Inspect participant incentives, costs and the checkable result.
  4. Use Inspect the evidence to see what the result does—and does not—establish.
  5. Choose Export project. Reopen that JSON with Open. Export your dossier for sharing.

Votre premier résultat utile

Commencez par la démonstration.

  1. Ouvrez le HARNESS, sélectionnez FR, puis ouvrez la démonstration.
  2. Examinez la mission synthétique et ses hypothèses déclarées.
  3. Exécutez l'expérience. Consultez les intérêts des participants, les coûts et le résultat vérifiable.
  4. Examinez les preuves pour distinguer ce qui est établi de ce qui reste incertain.
  5. Exportez le projet en JSON, puis rouvrez-le. Exportez le dossier pour le partager.
