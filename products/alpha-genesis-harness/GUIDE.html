A good first mission

English

Choose an outcome with a decision you can actually check: whether a shared resource is worthwhile, whether an assumption holds, or which complete route deserves a small experiment.

  1. State the outcome and material constraints.
  2. Add source identities and assumptions.
  3. Develop competing approaches with your chosen model or by hand.
  4. Run a bounded instrument with explicit inputs.
  5. Inspect the evidence, then keep, change or decline the proposal.
Français

Choisissez un objectif avec une décision vérifiable : l'intérêt d'une ressource partagée, la validité d'une hypothèse ou la solution complète qui mérite une petite expérience.

  1. Définissez le résultat et les contraintes essentielles.
  2. Ajoutez les sources et les hypothèses.
  3. Élaborez des solutions concurrentes avec votre modèle ou manuellement.
  4. Exécutez un instrument à partir d'entrées explicites.
  5. Examinez les preuves, puis conservez, modifiez ou abandonnez la proposition.

Use the intelligence you choose.

English

Manual: create a prompt in the app, copy it into your own AI chat service, then import the answer. Name the model and its role. The app does not log into that service. A consumer chat subscription is separate from API access.

Local or API: an optional local Python bridge supports configured provider protocols. Start it with the included source launcher; see connection instructions and bridge details. No credentials or model compute are included. Live authenticated integration is only established when the release evidence records it.

ChatGPT plan and Codex: official eligible pathways have separate consent, quota and commercial-approval requirements. A paid-edition plan connection is not operationally claimed until approved and live-tested. See the release matrix.

The demonstration is synthetic and offline. It does not know today's news. Freshness depends on actual source retrieval or evidence you supply.

Français

Manuel : créez une demande dans l'application, copiez-la dans votre service d'IA, puis importez sa réponse. Indiquez le modèle et son rôle. L'application ne se connecte pas à votre service. L'accès API est distinct d'un abonnement de clavardage.

Local ou API : un connecteur Python facultatif prend en charge des protocoles configurés. Cette installation avancée n'inclut ni clé ni consommation de modèle. Seules les preuves de la version peuvent établir qu'une intégration authentifiée a été testée.

Forfait ChatGPT et Codex : les parcours officiels ont leurs consentements, quotas et autorisations commerciales distincts. Une intégration commerciale ne devient opérationnelle qu’après autorisation applicable et vérification réelle.

La démonstration est synthétique et hors ligne. Elle ne connaît pas l'actualité. La fraîcheur dépend des sources réellement consultées ou fournies.

Read the verdict with its scope.

PASSED IN SCOPE — The declared check passed within its actual conditions.
REJECTED — The checked proposal failed a declared condition.
UNKNOWN — Evidence is insufficient to decide.
INVALID — The input or evaluation cannot support a valid result.

Une réussite est limitée à son cadre. Une hypothèse reste une hypothèse. Une source citée n'est pas automatiquement vérifiée. Un exemple synthétique ne prouve ni la demande réelle, ni la rentabilité, ni une découverte. Conserver un instrument ne prouve pas qu'il améliore le travail suivant.

The application can help structure and check work. It cannot turn unsupported model assertions into verified facts. Compare competent ordinary alternatives and permit the simpler solution—or no action—to win.

Keep control of your work.

English

The browser core handles your project locally. Exports are readable JSON, not encrypted archives. Browser saves can be cleared or restricted; use Export project for a portable backup.

Text pasted into a model service leaves your local workspace. The optional bridge sends requests to the configured endpoint. Credentials belong outside project files. Review content before sharing and only transmit information you are authorized to disclose.

Delete local exports with your operating system and saved browser data with your browser. This does not delete copies held by a provider or backup service.

Français

Le parcours principal traite votre projet localement. Les exports JSON sont lisibles et non chiffrés. Le stockage du navigateur peut être effacé ou limité; exportez vos projets pour les sauvegarder.

Un texte collé dans un service d'IA quitte votre espace local. Le connecteur facultatif envoie les demandes au fournisseur configuré. Gardez les clés hors des projets et transmettez seulement des informations autorisées.

Effacez les fichiers avec votre système et les données enregistrées avec votre navigateur. Cela ne supprime pas les copies détenues ailleurs.

Get unstuck / Résoudre un problème

The application does not open / L'application ne s'ouvre pas

Extract the entire ZIP first. Open START-HERE.html in a desktop browser with JavaScript enabled. Keep the app folder and all its files together. If a browser blocks local file behavior, use a different supported browser or the optional bridge.

Décompressez tout le ZIP, ouvrez START-HERE.html dans un navigateur et activez JavaScript. Gardez les fichiers ensemble. Essayez un autre navigateur pris en charge si l'accès aux fichiers locaux est bloqué.

My browser save is missing / Mon projet enregistré a disparu

Browser storage is tied to the browser, profile and sometimes local file location. Use Open to select your exported JSON. Without an exported copy or your own backup, deleted browser storage may not be recoverable.

Le stockage dépend du navigateur, du profil et parfois de l'emplacement du fichier. Rouvrez votre export JSON. Sans copie exportée ou sauvegarde, des données effacées peuvent être irrécupérables.

A model response will not import / Une réponse ne s'importe pas

Use the format requested by the generated prompt. Do not include credentials or executable HTML. Keep the original response, inspect the displayed error and correct the structure before importing again. Do not relabel an invalid response as a passed result.

Respectez le format demandé, conservez la réponse originale et corrigez sa structure selon le message affiché. N'y incluez ni clé ni HTML exécutable. Une réponse invalide ne devient pas un résultat validé.

A provider request fails or is cancelled / Une demande échoue ou est annulée

Check the configured model, account access, endpoint, prices and budget without sharing the credential. Do not assume a failure means zero charge. A provider may complete or bill a request already received. The manual workflow remains available.

Vérifiez le modèle, l'accès, l'adresse, les tarifs et le budget sans partager la clé. Un échec ne signifie pas forcément l'absence de frais. Le parcours manuel reste disponible.

I want to check my download / Je veux vérifier le téléchargement

The archive contains a release manifest and per-file SHA-256 values. Compare its whole-archive digest with the trusted public release before use. Advanced reproducible commands are in release verification. A checksum confirms bytes, not every software or scientific claim.

Comparez l'empreinte du ZIP avec celle de la publication de confiance. Une empreinte confirme les octets, pas toutes les affirmations logicielles ou scientifiques.
