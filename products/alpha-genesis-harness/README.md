## Develop and reproduce

The browser application has no bundled JavaScript library or build dependency. Python 3.10+ is needed only for the optional bridge and packaging. Node.js is a development test tool, not a customer prerequisite.

From this product directory:

```bash
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

From a repository checkout, build only committed source:

```bash
python3 scripts/package_release.py build --source-revision FULL_COMMIT_SHA --output /absolute/output
```

The command writes a deterministic ZIP, an SHA-256 file and an integrity receipt. It includes the selected product source, documentation and tests, with a complete file manifest. It neither packages the whole research repository nor imports its unresolved licensing. `--candidate` builds approved working-tree files and explicitly marks that archive as **not source-matched**.

Verify a download using the independently published archive digest and source revision:

```bash
python3 scripts/package_release.py verify /path/to/archive.zip --expected-sha256 PUBLISHED_SHA256 --expected-source-revision FULL_COMMIT_SHA
```

Within the repository checkout, add `--compare-source-revision FULL_COMMIT_SHA` to compare every packaged source byte with Git. A self-consistent manifest is not an authenticity certificate; obtain the digest from a trusted release channel. See [release process](docs/RELEASE.md).
