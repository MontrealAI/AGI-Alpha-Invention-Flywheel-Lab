# Generic reversible arithmetic study, 2026-11-18

Mission. Can the existing 42-term GF(2^12) multiply-add used in the public DQI lineage execute with fewer Clifford gates while keeping all 36 input and target wires and its 42 Toffoli gates? This is an ancillary circuit-length study. Google's DQI objective charges width, Toffolis and decoding error; no contest-score, acceptance, novelty or revenue claim follows from fewer CNOTs.

Input. Nasir Ali's Apache-2.0 multiplier tensor from nasir26/vqcc-kaggle at 55161390efc3e8604bab56f3f31e4abbf34c7764, results/dqi/scheme42.txt. Study uses generic field arithmetic only. No competition data, contestant submissions or hidden tests.

Acceptance. Gate list must compute (x,y,z) -> (x,y,z XOR x*y mod 4179), with no ancilla, phases or measurements. Compare against (1) local conventional rank-42 ancilla-free compilation, (2) competent all-start nearest-neighbor scheduling improved by deterministic full 2-opt best gain with fixed pivots. The latter uses the actual transition cost and the identical tensor. Candidate varies pivots via per-order dynamic programming retaining the stronger solution. Report real gate counts. Claim a circuit-length advantage only if at least 5% fewer CNOTs than the stronger local comparator. The public decoder's 42 product and 36-wire kernel cost is a separate strong bound; we do not have the official decoder bits or its kernel Clifford count for a head-to-head.
    
Verification. Use an independently written evaluator of emitted KMX lines, against polynomial carryless multiplication and reduction. Verify the full bivariate polynomial coefficients, preserved inputs and identity on arbitrary target (including all constant and linear terms), reject altered output. Parse the KMX using the released kickmix 1.0.0 parser if available. No outside spending, rule acceptance, account use, uploads or official scoring. Stop after one implementation and one deterministic CNOT search (maximum 3 minutes CPU) or absent required rights. Shipping a contest entry requires the primary and all companion official verifiers, independent scoring and authorization; do not submit.
