# ND02 · Can a split-page numerical table be received without changing its claims?

**Beneficiary decision.** A research editor needs a CSV whose quantities, units, groups and qualifying note can be traced to the physical table. An inaccurate value or dropped qualification is more consequential than a withheld export. Use the existing semantic source directly when available and suitable. Exact agreement with that source checks transcription only.

Freeze before inference or scored comparison. Use the first printed table of the public *Enterprise-011* report, a source pair not used in TD01. Its PDF summarizes simulated outcomes. The official HTML includes an additional success-rate column. Freeze the projection from HTML headings to the four printed headings: Regime → Regime (underscores rendered as spaces), Passed / runs → Passed, Mean complete-cost profit → Mean profit, Cash survival → Survival. Never treat the omitted column as a missing publication value. Require all 4 column labels, 4 row labels, 4 exact fractions, 4 dollar amounts and 4 percentages. Preserve signed decimals, currency signs, grouping separators and printed precision. The editor inspected source layout before registration. The model is given image pixels and a fixed task prompt only.

Add a separately authored, explicitly synthetic two-page metrology table with four rows, two independently grouped row labels, repeated headers, signed decimal bias and drift, explicit unit-bearing headers, and a material temperature footnote. The fixture's PDF is constructed independently of its semantic XHTML. Registration supplies cell boundaries and group-span positions to conventional extractors. Model sees the two full crops separately, including each note. All arms may use the registered topology; only the first physical column in the second data row of each control page may be carried, and only if its span anchor is present. A repeated header or footnote disagreement withholds the output. This small controlled table is not a population sample of scientific papers.

**Frozen arms.** (1) Authorized author HTML export projected onto the printed columns; emit a portable CSV. (2) Native text from the PDF using registered cell rectangles. (3) Tesseract English, each cell independently with PSM 7 and an unchanged whole-note line; charge preassigned geometry. (4) NVIDIA Nemotron-3.5-Parse (same exact checkpoint, processor, 4-thread CPU, greedy 2048-token limit, full fixed task prompt as TD01), one generation per crop, no retries or output-informed edits to values. Preserve raw results. Accept plain rectangular LaTeX tabular output, inert styling/escaping, declared spans, line-break/space normalization and matching repeated headers; unsupported notation or missing metadata withholds delivery. Do not reconstruct missing qualifiers or numerical values from the independent reference to rescue a model. Native, OCR and direct runs can use the actual PDF or HTML as specified. These are asymmetric information/cost conditions, disclosed rather than interpreted as an equal-input model race.

**Adjudication.** Compare all canonical ordered cells, exactly, and each registered page footnote. Check synthetic group ownership, duplicate continuation header and note. Reject a changed sign, precision/decimal, unit, denominator, footnote, grouping, source version, malformed matrix or stale crop. A CSV is released only for a complete accepted table. Report per-table and potentially per-field results, including all losses and raw route identities. Record validation, observation and tool timings separately, and actual measured peak memory where available. Engineering, geometry registration, private labor and commercial economics remain unmeasured. A future use case with no authorized independent reference requires different evidence; do not certify it from this study. Source crop coordinates, pinned inputs, exact control art and independent XHTML appear alongside this protocol.
