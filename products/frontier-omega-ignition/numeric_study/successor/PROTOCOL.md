# ND02-S · Deliver the newly supported calibration table

**Decision.** After the ND02 receiver learns to recognize a covered slot, can the lab deliver the newly accepted CSV more cheaply by retaining the authorized old model generations? This is a fixed marginal re-delivery experiment on the same public synthetic table. It does not test discovery on a new paper.

**Equal inputs.** Both arms receive physical calibration pages 1 and 2, registered as crop 2 `cb40b9fc30b45c9c281be8688055ea5f7a78040c4b0f81314b092a3b442f0f3c` and crop 3 `16ca34fb71508803d99bfe0daa66150f0123f5d6a26c41e930c1899d84695352`. Rebuild the fixed crops once; time this shared input preparation and include it in each counterfactual total. Both use the original independent reference, ND02-R decoder SHA-256 `9e8d696802b4978bd6fc38dbe9c894dad0754f1274d0f3049b43ef38f961c629`, original provider checkpoint `ea2e1fe486bea3e7d0d505df9bafa4ad562407a0`, official driver `fc3568bb3e9cf48dbcb8ce0cd4e25ee7360cec9fa9da331141497ecee5dcea41`, Python environment, hardware and fixed greedy CPU settings (4 threads, 2048 generated tokens). No external model/API/GPU.

**Fixed arms.** Reuse first: obtain legally retained raw files, check observation, input/weight and source identities, decode and reverify. Fresh next: validate provider files and execute exactly one new official driver subprocess per crop, same prompt/parameters and geometry as the originals, then apply the same decoder/independent verification. The fresh arm can reuse installed weights and filesystem caches; it cannot read the saved generations or proposed cells for construction. No retry or reroll. Run each delivery from a fresh output directory. Compare every delivered byte, all 25 cells, both notes, raw generation digests and any abstention. Retain outcomes when generation differs. A new loss must not be repaired in this comparison.

**Cost estimand.** Record elapsed/CPU and per-process peak RSS around each complete arm with a separate timed process. Report shared preparation and historical gross observation acquisition separately; credit all initial model attempts, including the initially withheld calibration result. Show both the marginal existing-archive decision and first acquisition plus storage, not just seconds saved by avoiding inference. Rendering, weight transfer, environment setup, decoder development, review, rights and ongoing maintenance each have distinct boundaries. Report unknowns without default-zero valuations. Historical full three-crop acquisition was 68.2773 s including the unrelated publication crop; the two observed calibration-call processes required 25.3698 + 26.5126 s. Strong outside option: source HTML/native PDF already produced the accepted calibration table; no requirement to call a model for this public source.

**Pass rule.** For technical reuse, verify all released bytes and both footnotes against a separate semantic parser. For a paired statement of observed marginal resource savings, require equal accepted CSV bytes and notes and strictly lower observed delivery wall time. One recorded observation in each arm gives no uncertainty estimate or population reliability. Distinguish the value of ordinary cache reuse from inherited scientific or institutional superiority.
