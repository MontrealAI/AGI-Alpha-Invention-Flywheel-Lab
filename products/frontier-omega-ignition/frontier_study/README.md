# A source changed the decision

MONTREAL.AI's engineering operator is considering self-hosted coding systems for a private pilot. The immediate decision concerns issue resolution under a mean charged-token allowance. It calls for comparable tasks, measurement of failed attempts and an audit on issues withheld from selection.

In the original opportunity study, five approaches could nominate candidates or guide further work. None could deliver this particular decision using the supplied evidence and permissions alone. A source published on October 22 changed that. Zhao, Poskitt and Lo made issue-level outcomes and metered token usage available for 1,800 attempts across 18 configurations. That allows a sixth approach: apply a prospective selection rule to an issue split and test the locked choice offline. An independent SQL analyst can use the records just as readily. The question about an actual private backlog still requires a private pilot.

## Reproduce the decision

From the IGNITION product directory, run:

```sh
python -B -m frontier_study
python -B -m unittest frontier_study.test_study
python -B -m frontier_study.test_study --record
```

`python -m frontier_study --mission mission.json --previous previous-report.json` compares a structured local mission with its prior watch record. The command reads no private services and executes no model or external actions. Available question types here are coding-pilot, model-provenance and science-replay. Unknown questions defer. The report identifies the exact source inventory, mission and observed evidence. The separate [Pairing Lab](../flagship/README.md) executes and independently checks the selected analysis.

## Registered counterfactuals

| Input | Result |
|---|---|
| Full mission and evidence | The five candidates are headline selection, an existing evaluator, fresh full-grid measurement, failure diagnosis and adaptive evaluation acquisition. A challenger combines the paired observations with a task-disjoint audit. Only this route meets the immediate governed decision. |
| Release record kept; projected matrix withdrawn or altered | Decision suspended. The bibliography does not stand in for the data. |
| Exact matrix restored; then unchanged on a second replay | The suspended decision reopens once. Unchanged evidence produces no reopening. |
| Measured cash cost required | Deferred. Token counts cannot establish a cash bill. |
| Beneficiary asks to authenticate a specific response | The proof-verifier opportunity replaces the coding proposals. A matching proof and commitment are missing. |
| October 13 cutoff | The historical subset contains HAL and matched-harness evidence. It cannot reproduce the registered October 22 dataset. This subset is a retrospective publication-date filter over sources inspected November 17. |
| Private backlog and fleet permissions granted in a synthetic sensitivity test | Multiple feasible courses are retained. The code requests a cost/outcome comparison; permission to investigate alone cannot establish a completed trial. |

This is a deliberately small, curated inventory with a deterministic joining rule. Forward discovery identifies what changed in published, verifiable resources. Backward discovery expresses the beneficiary's decision as required evidence properties. The challenger joins compatible data and transformations, while the parent program checks actual local bytes. A missing resource closes the opportunity until the evidence changes. Candidate generation beyond this finite inventory has not been qualified by this experiment.

**Mechanism in use.** Epistemic invention and problem transformation changed the means from recommissioning a complete trial to reusing already-graded cells with a disjoint evaluation. The ablation tests the contribution of those cells. Recursive selection includes a fresh local trial when its resources are available and explicitly keeps the conventional alternative. The relevant research foundations are [OUT-LEARN, pp. 3–10 and 13–17](https://montrealai.github.io/AGI-Alpha-Invention-Flywheel-Lab/out-learn.html) and [OUT-STRATEGISE](https://montrealai.github.io/AGI-Alpha-Invention-Flywheel-Lab/out-strategise.html). The evidence supports this finite implementation rather than the claims of either paper as a whole.

**Economics and claim limits.** Evidence acquisition and interpretation, implementation, original generation of the 1,800 runs, software checks, analyst effort and future hardware and review costs must all be distinguished. Replay requires no new inference and provides no measured paid-demand or complete-cost advantage. The before-window [Fan et al.](https://arxiv.org/abs/2609.20804) study and [HAL](https://arxiv.org/abs/2510.11977), the [November specialist study](https://arxiv.org/abs/2611.21515) and a conventional SQL analyst all count as real alternatives. Availability of this exact public corpus has a date; previous general impossibility, incremental institutional superiority and economic frontier crossing remain unresolved.
