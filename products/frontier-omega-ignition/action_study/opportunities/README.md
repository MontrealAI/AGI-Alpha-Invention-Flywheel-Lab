## An alternative outside the five

A shared verified model-asset cache could yield more immediate engineering value than another discovery stage. On the final review revision three hosted CPU operations each stopped before inference with HTTP 502. Their operation clocks totaled **68.2782 seconds** across concurrent jobs. The records identify neither the failing upstream request nor any billed amount. The successful prior run verifies that the exact pinned combination worked at an earlier time. The new preparer fetched the pinned 23,158,635-byte runtime from GitHub’s release CDN and verified the retained 2,497,280,736-byte model in 13.2205 seconds. A separate local execution verified both cached inputs in 2.6727 seconds with zero network attempts. Five tests exercised transient recovery, terminal failures and content quarantine. The preparer shares assets among steps on the same runner. It launches no inference. Hosted reliability and the benefit of sharing assets across jobs require separate measurement. That experiment has a narrow operational payoff. It cannot substitute for independently accepted scientific or engineering decisions. [Job and artifact identities](model_operations.json)

## Economics and acceptance

The primary productivity comparison requires a competent frontier agent and a competent fully human worker using conventional software, given the same task, sources, deadline and acceptance criteria. Separately compare direct AI, human-plus-AI, self-service SQL or specialist clients, and taking no action. A SQL replay measures computational agreement and resource use.
