# Evidence-to-Action Ω · Décider sur preuves

This offline instrument answers three different questions using fixed public sources. A new cutoff, source permission or repository budget creates a new decision. It can select a configuration for a later trial, change a shadow review or deliver a signed photometric difference. Its outputs carry recommendation authority only.

## Run the instrument · Exécuter l’instrument

From the extracted public recipient, choose a profile. The same commands work in the product directory of the repository.

```sh
python3 -IB action_study/desk.py example engineering-qualification > mission.json
python3 -IB action_study/desk.py decide mission.json > decision.json
python3 -IB action_study/desk.py verify decision.json --mission mission.json
python3 -IB action_study/qualification_choice/verify.py
python3 -IB action_study/observing/desk.py --check
```

Use a fresh output filename when preserving a previous decision. Set `max_repositories` to 10 and then 11. At ten repositories both rankings remain possible. An eleventh split qualifies the next-trial choice. The complete SQL control reads all 500 issue outcomes. The full census, inclusion rule, admissible bounds, disagreement counts and exact fractions are in [the engineering study](qualification_choice/README.md). The difference on this historical fixed benchmark establishes an internal qualification order. Adoption requires a fresh authorized portfolio and independent task acceptance.

For `gw-status`, test S240420aw at 2024-04-20T05:06:22Z and a second later. Try the observer-receipt clock. For `ztf-persistence`, withdraw the `alerce` source or change band and event time. The deadline and source policy stay part of the question. Each record reports consulted sources, their meaning and any remaining gap. A closed-coverage negative is restricted to the indexed population and interval. Read [the alert study](observing/README.md) and [the shadow protocol](shadow/REGISTRATION.md) for clock definitions, source limitations and independent comparators.

Le premier exemple détermine quelle configuration mérite le prochain essai interne. Modifiez le nombre de dépôts permis et relancez le calcul. Pour l’alerte gravitationnelle, avancez d’une seconde ou exigez une heure de réception chez l’observateur. Pour la photométrie, choisissez le filtre et retirez l’archive secondaire. Chaque décision est liée aux sources autorisées et à la question exacte. La date d’une exposition, la diffusion d’un avis et sa réception par une personne sont trois événements distincts. Le dossier public contient les réponses historiques des archives. N’utilisez que les paquets prévus par le protocole pour une comparaison à l’aveugle.

## Independent checks and limits

The 500 SWE-bench labels compare published configurations. The LVK XML and text streams share an issuer. Source hashes bind bytes for repetition and checking. They cannot establish event truth or beneficiary value. The benchmark carries no fresh private issues, and the observatory study has no enrolled observers. Unknown labor, bills, support, demand and downstream value remain unknown. [Five investigated opportunities](opportunities/README.md) · [Release engineering construction](construction/README.md)

The private workbench lists the evidence mission in its existing mission picker. It saves the selected scope, evidence authority and receipt per revision. Amend to change permissions, population or cutoff. A recipient contains the scoped public source snapshot needed to reproduce its decision. A reviewer with a previously saved fingerprint can add `--expect SHA256`. Public sources may contain later records. Only applicable records enter the calculation.
