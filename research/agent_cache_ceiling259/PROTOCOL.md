# Agent cache ceiling 259 — frozen workload and decision contract

Independent research only. Base 3cc6bc95a13f991b5158e5bd5064b766b21632a4. No financial owner source, accounts, keys, existing release, deployment or outreach. Not P0 migration or flagship admission.

**Opportunity:** An instrument to determine when spending engineering effort on cross-model cache warming cannot deliver a proposed complete-cost saving, even with ideal reuse. A necessary-condition certificate is useful before commissioning actual serving trials; it is not an optimizer or empirical profit claim.

**Strong alternatives and selection:** (1) established per-step routing and ShadowPrefill (arXiv:2611.13176v1, 2026-11-09); (2) cache-aware session admission/recovery with ordinary routing (arXiv:2611.13412v1, 2026-11-10); (3) exact-match current serving without speculative compute, including vLLM/Ray native caching; (4) no entry. The first two already target switching cost and sustained cache collapse, respectively. Neither generic shadow warming nor concurrency budgeting is an established residual. Select only the evidence instrument, not a commercial offering; deployment remains abstain.

**Source:** Azure/AzurePublicDataset, release ghcp-coding-agent-2026, dates June 1 and June 7 2026 fixed before access. CC-BY metadata-only dataset; cite Liu et al., Agentic Coding in the Wild, arXiv:2608.00101. For each date use all sessions in the first two lexicographically named .jsonl.gz shards in the day archive (no selecting after viewing). Date 1 development and date 7 descriptive transfer; no optimization/tuning or claim of independent blinded holdout. Record actual archive and shard SHA256, counts, errors. No row IDs, timestamps, model names or tool content published; only aggregate counts. No private data. Do not persist raw archives beyond transient processing.

**Fixed estimands:** For each turn, sort LLM calls by parsed start time; classify as first, overlapping/ambiguous, same model, or switched model, comparing with immediately preceding call only if preceding end <= start and timestamps/model labels are unambiguous. Classify ties and overlapping calls conservatively as ambiguous; reset across turns. Include all valid token accounting rows regardless of outcome. Report malformed/ineligible rows separately; no silent drop, never extrapolate selected shard counts to population. For every class sum prompt P, cached C, output O, miss M=P-C. No assertion that adjacent prompts share text or that model outputs/acceptance are interchangeable. Maximum extra cached tokens on the defined nonoverlap switch subset is M_switch, even for an oracle that converts all its misses for free. Max on all calls M_all. This is an optimistic upper bound on potential *input charge* reduction at fixed accepted call trace, not physical compute reduction, latency, ability to omit calls, or provider profit. No shadow work, rent, opportunity cost or support saving is credited.

**Conditional pricing:** for common normalized uncached-input price 1, cached/input q in {0,0.1,0.5,1}, output/input r in {1,4,10}, baseline B=M_all+q*C_all+r*O_all; upper reduction fraction (1-q)*M_switch/B and all-call bound. Report zero denominator as null. Heterogeneous prices unknown. An actual contract requires per-model price evidence, measured shadow/host costs, rights, baseline acceptance and voluntary funding; no threshold from these data establishes buyer willingness. No price assigned to actual customer.

**Tests before data:** deterministic tiny accounting fixture covering first/same/switch/overlap/tie, malformed counts, q=1 zero gain, all-call >= switch bound, denominator zero, exact integer conservation, and rejection of missing date or unexpected archive schema. Authored tests are correctness only, never economic validation. One first execution per registered data arm; retain failed arms and correct versioned errors if necessary. Actual platform limits apply, no paid resources. Record CPU/wall and unknown billing. If archive inaccessible, stop that arm with exact error and no simulated substitute.

**Acceptance:** source-bound tool and tests; actual data acquisition and aggregate execution separate; no buyer/complete economics/causal gain/native profit/recursive improvement until further evidence. Compare strong serving baseline with real measured hardware in a later authorized trial only if evidence supports a residual; no $3B inference.
