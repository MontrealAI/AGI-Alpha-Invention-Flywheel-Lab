## Decisive missing means

A generated document's surface appearance may remain plausible after a model release while semantic navigation (headings, links, table headers, images, language) regresses. Construct an **offline version-bound, source-first accessible HTML compiler + independent structural audit and change gate** for a small typed content grammar. Reject unsafe/unknown content types, raw markup, missing semantics, altered frozen output, and regressions between two supplied releases. Record hashes for exact source and output bytes. Never claim this validates *semantic* correctness, assistive-technology experience, WCAG/EN 301 549/CAN-ASC-6.2 conformance, or AI model provenance; source/model labels are declared, not authenticated.

**Accepted small prototype:** from a declared typed record, emit exactly one self-contained UTF-8 HTML page with escaped human content, lang/title/h1/main, ordered headings, named links, meaningful declared image alt text, and tables with header/caption. A stand-alone verifier reparses its exact bytes, hashes the canonical record, and checks navigation invariants. A model-change gate compares two pinned record/HTML/receipt triples and rejects a regression even if the new model label changed. It may approve an *unchanged structural result*, never conformance. Valid authoring with missing actual alt meaning must be rejected or recorded as requiring independent semantic review, not auto-certified.

## Preregistered comparison / test boundary

At least four arrangements: **A** constrained structured output + structural audit (constructed challenger); **B** capable human accessibility specialist with conventional software and assistive-technology/user evaluation (unrestricted competent alternative, **unmeasured** here); **C** post-hoc WCAG/HTML repair plus independent assistive-technology QA (unmeasured comparator); **D** no-deploy (valid outcome). Do not imply A beats B or C without same-content time, full cost, correction, support, human intervention, and independently checked acceptance. A separate alternative is a specialist-supplied accessible PDF; full PDF/UA verification is outside this prototype.

Pre-frozen test classes: (1) valid structured document, (2) HTML/script attribute injection escapes, (3) nested/invalid types fail, (4) missing/generic image alt fails, (5) unnamed/unsafe link fails, (6) malformed heading order fails, (7) missing header/caption table fails, (8) invalid language fails, (9) unauthorized change to HTML fails, (10) tampered/missing receipt fails, (11) modified source bytes fail, (12) candidate baseline mismatch fails, (13) intentionally inaccessible candidate rejected, (14) valid same semantic structure passes, (15) no unwarranted conformance/paid-commerce claim, (16) unknown model version allowed only as declared metadata; never validate model identity, (17) duplicate/stray structural landmarks fail, (18) user-supplied raw HTML not executed.
