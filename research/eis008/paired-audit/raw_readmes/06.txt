(1) This repository contains all raw files relevant to impedance spectrum testing, including not only the impedance spectrum of the membrane electrode assembly (MEA) and stack but also time-domain data recorded during testing, such as voltage, current, temperature, and flow rates.

(2) The dataset is divided into four subsets: dataset 1 is designated for base model training, while datasets 2, 3, and 4 are utilized for validation of transfer learning in model adaptation.

(3) The extracted predictive input features and corresponding impedance spectrum are documented in the dataset files within the code repository.
