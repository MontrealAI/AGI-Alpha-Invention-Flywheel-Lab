# Existing complete algebraic alternatives and scope

These controls were derived and executed before inspecting the builder's candidate. `baseline_audit.py` imports no builder code and checks all component matrix elements using integer Gaussian arithmetic.

## Ordinary concatenation already constructs the unrestricted target

The primary predecessor `https://arxiv.org/html/2510.20728v3`, AppendixE equations22–23, defines a six-physical-qubit, four-dimensional, distance2 code. Write t=(t1,t2,t3), phi(t)=(t1,t2,t3,t1 xor t2 xor t3), and psi(t) with its final parity bit flipped. Its first three logical states are one-quarter times the sum over t of sign s_j(t) times [|00 phi(t)>+|11 phi(t)>], with s0=1, s1=(-1)^(t1+t2), s2=(-1)^(t1+t3). Its fourth state is one-quarter times the sum over t of (-1)^t3 times [|10 phi(t)>+|01 psi(t)>]. Physical phase weights are(1,3,2,2,2,2) modulo4. The logical gate is controlled-S in that stated four-state basis. The first three states share support and use sign cancellation; our disjoint-support candidate certifier is deliberately not a general validator for this baseline.

The executed baseline audit checks exact orthonormality, all19 identity/weight1 Pauli compressions, and the physical phase action. X0X1 compresses to diag(1,1,1,0), proving this outer code has exactly distance2.

Use the standard Steane seven-qubit code as inner code. Its |0> is the equal superposition over the eight words generated by1111000,1100110,1010101; |1> is their bitwise complement. All nonzero words of the first support have Hamming weight4. Therefore(S dagger)^tensor7 implements logicalS, and the audit verifies all211 identity/weight≤2 Pauli compressions exactly. X0X1X6 acts as inner logicalX, proving exactly distance3. Original construction reference: `https://arxiv.org/abs/quant-ph/9605021`; the phase orientation is explicitly documented by IBM Quantum: `https://eu-de.quantum.cloud.ibm.com/learning/en/courses/foundations-of-quantum-error-correction/fault-tolerant-quantum-computing/controlling-error-propagation`.

Replace each of the outer code's six physical qubits by a Steane block. Apply S to the power -w_j on every qubit of blockj. The resulting42-qubit code implements the same logical controlled-S using42 single-qubit phase locations, including7 S,7 S-dagger,28 Z operations, if these are native phase primitives.

The distance bound is compositional, not an unexecuted exponential state simulation: any Pauli of total weight≤5 can act with weight≥3 on at most one inner block. Every other inner restriction is a scalar by the inner distance3 check. The remaining restriction is an arbitrary operator on at most one outer qubit, and is scalar on the outer code by its distance2 check. Thus the concatenation detects every Pauli of weight≤5 and has distance≥6. A physicalX on sites0,1,6 in each of the first two Steane blocks lifts the outer X0X1 witness using weight6, proving exactly distance6. The code is non-Pauli-stabilizer by the same Clifford-trace argument used below.

This is a constructive inference combining published ingredients and exact component checks. It is not presented as a quoted42-qubit catalogue entry or a newly discovered capability. Generic existence of a K4,d≥3 code with this local-phase controlled-S action is consequently not a valid novelty claim. A smaller construction can be a distinct mathematical resource result; comparing its data-qubit count with42 does not establish lower complete-system cost, especially if its distance is3 rather than6.

## Ordinary gate synthesis is another functional control

Controlled-S has the exact two-CNOT/three-T-type-gate decomposition: T(a),T(b), CNOT(a,b), T-dagger(b), CNOT(a,b). On computational input(a,b), the phase exponent in units pi/4 is a+b-(a xor b)=2ab. The audit checks this truth table exactly. Existing fault-tolerant stabilizer architectures can implement such a logical circuit, with nontransversal T implementation resources, preparation and correction. This alternative does not satisfy an all-local-quarter-phase gate constraint, but supplies a complete ordinary functional route to the logical interaction. Magic-state preparation, decoder, hardware and error-rate costs cannot be set to zero.

## What the sparse certificate proves

For four normalized codewords with disjoint computational-basis supports whose union has Hamming distance≥3, any Pauli containing X orY of total weight≤2 maps every occupied basis state outside the union. Its code compression is therefore zero. Pure Z and ZZ off-diagonal matrix elements vanish by disjoint support. Equal diagonal Z/ZZ moments finish the detection equations. Detecting all weight≤2 Pauli operators implies correction of arbitrary single-qubit errors by the Knill–Laflamme criterion, including single-qubit amplitude damping as a channel in their linear span. It does not correct arbitrary two-qubit errors.

Physical products of S powers are Clifford. If the code were a Pauli stabilizer code, any such code-preserving Clifford would induce a logical Clifford. For a CliffordV, |traceV|^2 is the trace of its Pauli conjugation action: the fixed binary Pauli labels form a subspace and their signs a character, so the trace is0 or2^r. Controlled-S has |3+i|^2=10, contradicting that property. This proves non-Pauli-stabilizer status. It does not prove inequivalence to stabilizer codes under arbitrary local unitaries or a practical advantage.

## Novelty and implementation reservations

The SSLP framework, residue supports, Z-moment LP, exact rational reconstruction and independent formal verification are prior art. arXiv2504.20847 explicitly introduces the general(n,K,3) diagonal-gate construction before focusing mainly on K2 examples. arXiv2510.20728v3 adds a Lean-certified small-code catalogue, residue-degenerate K4,d2 controlled-S and K2,d3 transversalT. The latter work was accepted by PRX Intelligence on6October2026 as 'Lean-verified discovery of exact nonadditive quantum codes with AI assistants', DOI10.1103/vn2w-p188. These specific published examples do not establish a smaller K4,d3 controlled-S code, but absence from these sources is not a novelty proof or an exhaustive classification.

The candidate must supply a new exact construction or another material functional result, not claim the search/verification workflow as the invention. An isometry simulator can validate ideal logical encoding, gate, specified local error channel and recovery. It does not construct physical encoding, stabilizer/syndrome measurements or a feasible recovery circuit, and cannot establish a fault-tolerance threshold or hardware/process superiority. All such implementation and commercial-demand costs remain separate and unknown here.
