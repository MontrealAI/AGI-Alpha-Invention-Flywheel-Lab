# Canonical channel terms before financing

Valid optional channel-term omissions previously survived connected config
admission unchanged while ChannelBook filled their defaults. The financed work
therefore recorded different terms from the purchased contract. The saved
counterexample reproduces this data mismatch without opening a financial account
or running commerce.

Connected validation now returns a detached config whose channels contain the
shared validator's normalized terms. Financing, purchase, source binding and
resume consequently use one canonical contract. Valid omissions remain supported;
no checker, required field, lead guard, default cost or pricing policy changed.

The 34 focused tests include optional omissions, exact agreement between financed
config terms and the standalone purchased contract, caller immutability, and
idempotent config binding for resume. Complete default configs remain equal to
the original defaults. Composed release qualification remains a separate gate.
