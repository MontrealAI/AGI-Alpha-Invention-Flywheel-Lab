Abstract

AGI ALPHA aims to construct verified instruments that improve subsequent invention and support useful, economically viable delivery. This edition investigates that aim using two real perturbation-data families and a bounded executable representation language. It continues a verified release whose inherited memory matched ordinary reuse and conventional construction, rather than improving on them. The new work qualifies actual data interfaces, preserves an ordinary-extraction failure, generates arithmetic representations from observed single-intervention effects, and repairs a consequential exchange-symmetry defect through an independently reproduced constraint. These are distinct engineering and experimental contributions. On 44 protected Norman pairs and 58 protected Wessels pairs, the repaired constructor fails the declared advantage criterion against strong conventional controls. The fresh inherited construction beats additivity but loses to matching mean and full-information ridge; equivalent ordinary reuse gives identical predictions and generated policy selection retains the incumbent. The resulting engineering qualification does not establish a previously inaccessible biological capability, improved invention policy or a commercial flywheel.

3. Executing construction and verification

3.1 Generated representations and bounded execution

The domain constructor begins with observed single-intervention effects relative to the same control. It fits centering, scale and three principal coordinates using development inputs only, with deterministic component-sign conventions. Arithmetic trees combine the resulting six A/B coordinates. The finite grammar supplies addition, subtraction, multiplication, bounded division, minimum and maximum; trees have bounded depth and node counts. At most eight generated basis functions augment a residual ridge model over the additive prediction. PCA, ridge, normalization and arithmetic primitives are developer-authored. Runtime-generated compositions are not unrestricted invention.

mechanisms/policy006.py generates versioned arithmetic policies through bounded synthesis/mutation. Its generic action-selector interface proposes measurement, representation, construction or repair action identities under explicit budgets; a trusted broker owns actual effects. The Norman constructor uses generated trees as representations through an explicit developer-supplied terminal correspondence. That use is distinct from proving that a learned general discovery policy has improved.

The historical Norman proposal trace used a hash-qualified host copy of Omega’s original Program.create and mutate. Its recovered archive has no established module license, so that module is not vendored or represented as installed by the public reproduction. The public historical run instead replays the exact recorded native proposals. A separately authored bounded fallback generator executes as a separately labeled development experiment; it is not native-regeneration parity or live-model performance. Source/archive identities and this licensing boundary remain part of provenance.

Generated arithmetic representations execute as JSON data in the qualified seccomp interpreter. They cannot import arbitrary generated Python or choose host files, credentials or network endpoints. Trusted array fitting and data acquisition occur outside that interpreter and are identified as trusted application effects. The trusted supervisor records resource receipts and applies per-process limits. Subsequent review found standalone termination and fast-exit storage-enforcement defects, documented in Section 5. This supervisor is separate from the generated-program seccomp boundary and does not establish exact escaped-descendant CPU accounting.

3.2 An observed criticism becomes a general construction

The first nominated representation depended on the arbitrary order of the two simultaneous intervention labels. Swapping A and B changed a prediction by as much as 0.430802 on exposed development cases. The initial grammar permitted ordered representations and did not impose the unordered-input contract. A separate verifier reproduced the actual prediction defect and emitted an established exchange-symmetry constraint bound to source, artifact and data identities.

The structural donor is the established finite-group averaging construction. The supplied source graph represents two exchangeable inputs contributing to a joint output. The matcher returns both permitted input correspondences, rather than manually selecting a desired A/B labeling. Simultaneous unordered inputs and matching units are applicability conditions. Ordered interventions do not admit this action.

The constructor consumes the adjudicated constraint by replacing each generated basis with

ϕsym(A,B)=12{ϕ(A,B)+ϕ(B,A)}. \phi_{\mathrm{sym}}(A,B)=\tfrac12\{\phi(A,B)+\phi(B,A)\}.

It then refits using the same development data and unchanged prediction objective. This is a generic transformation of every generated basis, not a patch for one named pair. Group averaging is known mathematics and its implementation was a supplied primitive; the executed contribution is the constraint-triggered application to the selected generated artifact, not autonomous invention of the primitive.

4. Prospective protected specification

The registered primary endpoint is RMSE across the unchanged 1,000-gene panel for each protected pair. Acceptance requires at least 5% median pair-relative RMSE improvement against every qualified named control, improved pooled RMSE against every such control, at most 10% ninetieth-percentile pair-relative loss increase, and finite outputs with exact pair/gene identities. The complete controls are exact A+B-control, Systema MatchingMean, exactly (A+B)/2 when both singles are observed; full multioutput linear-kernel ridge on all 1,000 symmetric single-effect features; and additivity plus the per-gene development-mean residual. The fourth control was added before protected execution because the constructed model’s unpenalized intercept could otherwise explain apparent benefit. The full ridge control standardizes the complete symmetric vector A+B-2control using fit data only. Both direct and additive-residual targets search nine ridge strengths from 1e-4 through 1e4 on the declared fit/calibration split, with deterministic tie rules, before all-development refitting. Direct ridge, residual ridge and training-mean controls are also reported separately. Hyperparameters are selected before protected outcomes, using 60/20 Norman and 75/25 Wessels fit/calibration pairs. A coordinatewise ridge does not qualify this control.

The secondary endpoint ranks observed absolute deviations from additivity, using a fixed top-100 relevance set, NDCG@50 and source/pair/gene hash tie-breaking. These are observed condition-mean deviations. They are not biological interaction significance, a cellular false-positive rate or a clinical endpoint.

Candidate, comparators, verifier, protocol, task identities and budgets are frozen before the fixed protected panels are evaluated. No scientific confirmation alpha is newly spent. The practical thresholds describe this finite cohort; correlated means and shared measurements do not support gene-independent standard errors or biological-population confirmation. Outcomes used for repair become exposed and cannot retain confirmation status.
