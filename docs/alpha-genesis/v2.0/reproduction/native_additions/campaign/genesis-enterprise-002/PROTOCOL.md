# GENESIS 002 — registered integration protocol

**Scope:** prospective finite authored integration and regression reproduction. All generated inputs, buyers, costs and prices are synthetic. Native money uses integer microUSD; input quotes use integer cents. No provider calls or external financial actions.

## Hypotheses exercised

- A qualified existing method may win over the product's own generated or inherited method.
- An inaccessible frontier announcement cannot be selected as installed execution capacity.
- A buyer can refuse; an unaffordable or nonpositive route cannot operate.
- Fixed discovery/setup costs remain costs even if the subsequent market disappoints.
- Accepted independent production must precede collection; rejected production is refunded.
- Earned-only continuation must be funded by current unrestricted native earnings, never expected research value.
- A method-selection experiment must preserve strong conventional ties and reject unsupported higher-order claims.

These are engineering correctness properties, not hypotheses that prove a novel science or market.

## Fixed primary

Use the unmodified `INPUT.json` with `central` stress. There are six consecutive operating slots and three declared offers. Quote and method are selected before constructing a delivery from a distinct source-bound admitted input. The initial method comparison uses three public-code adapters; the fourth announced capability remains unavailable. Every selected delivery is produced using the chosen existing adapter, separately checked, and compared semantically to the native admitted reference. A native zero-cost record binds the actual produced artifact/check receipt.

The default continuation after the first slot is earned-only; separate declared available-cash tests do not change this primary. The first production may be seed-funded. Seed still backs permanent native principal/fee reserves; no seed-independent replication or seed payback claim follows.

After operating expenses, the scenario provisions 20% of positive modeled pre-research surplus. This is an authored simulation provision, **not real tax advice**. A US$5 research action is eligible only if its supplied US$8 prospective benefit exceeds cost and native unrestricted earnings plus available cash cover it. Those supplied values are not measured return on research. All expenses remain in reported profit.

The research method chooses a routing map on six tasks per each of three source families. It freezes that map before executing 24 confirmation tasks from a distinct seed, with learned routing, direct conventional and generated comparisons. These are synthetic partitions of a finite task family, not private independent discovery campaigns. Replaying them later is regression, not fresh statistical evidence. Counted work is mapping-stage row visits only, not complete CPU or cost.

## Negative comparisons

- No-demand stress changes operating buyer values after the original startup commitment. Expected result: no collections, original sunk costs retained.
- Payment failure permits acquisition effort but no funded order/production. Earned-only continuation subsequently remains unavailable.
- Failed acceptance injects an invalid outcome scope. It must refund, keep incurred costs, and not fund another operation with imaginary profit.
- Ex ante known negative total route: refuse startup before account creation.
- Low research option value: retain profitable operations but decline the research expense.
- Explicit available-native-cash arm: permit declared existing opening cash without copying balances or reseeding.

## Integrity checks

Separate operating enumeration checks each eligible price/method pair. Native accounting replay checks its actual journal. The operating audit independently recomputes artifact acceptance and ties each decision to the ledger prefix before that decision. It rejects altered source/configuration, inaccessible methods, changed prices, extra/missing actions, fake profits, mutated output, fabricated funding and extra episode files. Fresh starts refuse existing paths. Resume refuses missing custody material, changed configuration or a stale completed report; interruption tests preserve the original signing key and unique spend identity.

## Advancement criteria

Local integration, current-head CI, repository publication, a released-source run, independent scientific advantage and real profitable operation are separate states. Publishing these tests is not a claim that the remaining states passed. No private account state may be committed to GitHub.
