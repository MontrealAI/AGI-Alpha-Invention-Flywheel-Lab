THE NEW CONSTRUCTIVE QUESTION
Do not only ask what you must know to succeed. Ask what you could build so that you no longer need to know it.

A second intelligence can reveal what an answer missed. The deeper opportunity is to turn the verified gap into a construction: a better observation, a more capable action, or an arrangement that makes valuable cooperation worthwhile.

THE COUNTEREXAMPLE

Every pair can work.
All three can still fail.

Exactly one of three fictional sources is unavailable. Each other source can supply the one unit we need. With no status information, which single source should we choose?

Possible situationActions that succeed
A unavailableB or C

Each pair of situations has a common action. All three together have none. Pairwise criticism alone misses the obstruction.

One truthful question—“Is A unavailable?”—is enough: choose B if yes, A if no. A separately built robust route could remove the need for that question altogether. Both responses must earn their complete cost and preserve the same promise.
