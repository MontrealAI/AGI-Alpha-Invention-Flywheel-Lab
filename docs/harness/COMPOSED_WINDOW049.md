# Complete public quantity/sequence/game composition049

This opt-in increment reuses the existing complete-offer selector, exact native
account, finite quantity allocator, paired `ChannelBook` forecasts, one-window
sequence calculation and finite follower-game selector. It creates no ledger,
optimizer, market demand, future cash or autonomous-invention claim.

For a fresh simulation configuration, set the existing sequence policy's
`composition` field to `complete-offer-quantity-v1`. It requires a complete-offer
market with explicit admitted `requested_jobs`, a costed `channel_menu_policy`,
`capacity_menu`, and `ranking_arithmetic: exact-rational-v1`. The existing
single-order pricing/method rules still reject hypothetical `repeat_horizon`
and `future_equivalent_jobs`; this increment values a separately identified
future window through the existing sequence mechanism.

Until the independent owned-access repair is adopted and qualified, this path
requires `owned_contact_count:4` and channel `owned_audience_count:4`, matching
current initialization/planning/exposure/audit semantics. An inconsistent48-owned
channel is rejected rather than paying for inaccessible reach. Fewer than four
actual buyers create no extra identities. No policy default changes.

Public context groups share the same declared profile and observed expenditure.
Inactive buyers and pending commitments are excluded. Future work must be
requested by every buyer in its group, already admitted, disjoint from all used
and currently shortlisted component work, and disjoint within the counted pool.
This conservative intersection can produce no opportunity for heterogeneous
requests; no matching work is invented. Acquired active relationships enter
future existing-customer access; all initial-owned and acquired-active contact
costs are charged conservatively. The forecast counts target-group contacts but
pays for the full channel's unsuccessful and irrelevant attempts/qualification.

A packet's three units and complete production/checking/support/onboarding,
payment, tax and evaluation costs stay attached to its actual admitted profile.
The forecast clips the declared quantity menu to actual current supplier room
and enumerates zero additional units when capacity is inadmissible. This physical
contract bound prevents a huge policy integer from causing unbounded search; it
is not a buyer/business/profit ceiling. It includes
purchased units rather than contract count, checks full production interval,
strict expiry, lead time, horizon and declared outages. A channel-first route
costs its contingent later capacity as an earned-funded obligation, but only
the selected first invoice executes. Every later action must observe, replan
and reserve again. Shared expansion-benefit identity prevents current recourse
and sequence forecasts from adding returns for the same expansion window.

Current seed-eligible delivery locks reduce available cash; they do not erase
unrestricted earnings. Only operating costs reduce the earnings preflight.
Expansion invoices and contingent capacity remain earned-funded and the outer
native allocator enforces total cash, current delivery principal protection,
earned funds, liabilities, exclusivity, work identity and the chosen risk policy.
The sequence's future reserve calculation is a planning preflight, not a claim
that unexecuted future work has an account reservation or spending authority.

Native preparation preserves both sequence and quantity selected flags; actual
quantity invoices use their selected identity and units. Independent audit
reconstructs public expenditure from prior decisions, accepted commitments and
refunds, then rederives the forecast, game certificate and native first effects.
Finite follower responses are authored forecast stress, not observed rival
agents or proof of general game equilibrium.

## Finite comparison and reproduction

`campaign/composed-window-049/PROTOCOL.json` and
`connected_enterprise.composed_window049.PROTOCOL` specify four separate
US$100,000 accounts: central/no-demand crossed with conventional/composed,
21 scheduled operating days plus ordinary drain, one fixed seed and cohort.
The conventional incumbent has the same public market and allowed costed
channel/capacity contracts, exact price ranking and follower game. The composed
arm pays an additional US$5 setup and US$0.05 daily planning envelope. Actual
host/model/developer billing remains unknown. All four registrations must be
prepared before operation; no losing arm, seed, price or horizon is replaced.

```sh
python3 -m connected_enterprise.composed_window049 prepare --case central --arm conventional --output /absolute/new/central-conventional
cd /absolute/new/central-conventional/source
python3 -m connected_enterprise.composed_window049 run --output /absolute/new/central-conventional --max-events 2
python3 -m connected_enterprise.composed_window049 run --output /absolute/new/central-conventional
python3 -m connected_enterprise.composed_window049 verify --output /absolute/new/central-conventional
```

Repeat prepare/run/verify separately for the other three fixed case/arm pairs;
never pool balances. Registration and complete financial state stay private.
`PUBLIC.json` contains only compact checked outcomes, source/config/result hashes,
invoice descriptions and unknown-billing fields; it contains no signing keys or
account recovery authority. Before operation/audit, the module regenerates the fixed cohort from the frozen
generator seed/count/packet dimensions, compares timing-neutral manifest identity
and exact admitted artifact bytes, and rejects substituted valid cohorts. It
resumes the same account, requires unchanged native history after completed resume, and independently audits.
A resource interruption preserves the authenticated checkpoint for the same
output. Commands above are interface instructions; concrete execution receipts
must be inspected before claiming a run completed.

This two-policy engineering pair is **not** the requested competent-baseline,
commerce-only, capability-only, joint and tuned-fixed-split comparison. That
broader comparator scope remains outstanding. No joint-policy superiority,
fresh discovery-method benefit, annual profit, actual commerce or US$3billion
milestone is claimed here, even if this finite composition works profitably.

## Qualification and concise lessons

Run `python3 -m unittest tests.test_connected_composed_window049 -v`. The exposed
native fixture requires actual sequence acquisition, actual earned two-unit
sequence capacity purchase, accepted/settled three-unit packets, a rederived
follower-game certificate, hidden-budget/future-seed invariance, unchanged
same-account resume, independent audit and rejection of forecast tampering.
Pure cases cover disjoint work, strict expiry, outages, no demand, empty reach,
liquidity, inactive buyers and seed/earned funding distinctions. Existing sequence
and quantity regressions remain required. Full source-qualified integration and
downloaded-release operation are separate gates.

Development found public lifecycle replay omitted expenditure fields needed by
the new path: reconstruct them from native prior observations, do not read final
private budgets. Channel-first/capacity-first actions originally shared an ID:
include the action kind and regression-test uniqueness. Critics found owned-cost
undercount and inactive-owned forecasts: require coherent actual owned identities
and exclude inactive value. Existing sequence over-deducted seed-eligible locks
from earnings: split available-cash and earned-invoice preflights. A tamper test
initially assigned an unchanged value: force an actual changed field. These are
engineering repairs, not new economic discoveries; old development receipts
remain source-specific and do not qualify the repaired source.
