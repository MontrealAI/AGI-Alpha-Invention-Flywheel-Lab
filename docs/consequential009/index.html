3. Constructed means: symmetry to a measurement extension

For a passive branch at positive angular frequency omega, the admittances are 1/R, j omega C and 1/(j omega L). The developer supplies these constitutive laws and their units. The program solves the exponent condition that every branch admittance scale by the same factor 1/a. It therefore emits R->aR, L->aL and C->C/a, together with coverage of the parsed branches and applicability exclusions. The algebraic derivation is executed; neither the physical laws nor the source selection are claimed to have been discovered autonomously.

R and L scale by a; C scales by 1/a; every branch admittance scales by 1/a.

At fixed normalized source voltage, the complete nodal matrix and forcing vector both scale by 1/a. When the nodal system is nonsingular, its voltage solution is unchanged at every node and every frequency. Consequently, more voltage samples from this same model cannot identify global impedance scale. Input current, and hence input admittance, scales by 1/a. An admitted current observation changes the available information rather than merely searching harder over voltage reconstructions.

Yv=b → (Y/a)v=b/a; Vn/Vin unchanged; Iin/Vin → (Iin/Vin)/a.

The implementation uses exact rational complex arithmetic and Gaussian elimination, avoiding floating-point equality as evidence of structural non-identifiability. The initial voltage-only toolbox cannot express an input-admittance action. A generated extension adds that observable with its physical unit, frequency, acquisition-unit weight, derived symmetry and ancestry. A greedy finite strategy builder then chooses actions that separate unresolved pairs. The selected plan retains exact response tables, uncertainty policies, unresolved witnesses and source identities.

6.1. A second construction from the verified gain defect

The gain-confounding witness was converted into a typed construction constraint and a paired-reference observation primitive. The new procedure measures normalized input current with a parallel reference conductance switched off, then switched on, using the same complex sensor transfer during both readings. It emits an executable paired-measurement DSL and a rational normalization expression. This changes the information available under stable but unknown gain. The reference technique is known ratiometry; no invention priority or superiority over the same-reference conventional control is claimed.

z0 = gY + e0; z1 = g(Y + G) + e1; Yestimate = Gnom z0/(z1 − z0).

In the noiseless exact-reference case, the shared complex transfer cancels algebraically. The executed protocol allows reference conductance between 0.99 and 1.01 times its nominal 0.001 S, common gain magnitude at least 0.5, and coordinate noise at most 1e-10 S. These are authored conditional bounds, not laboratory calibration. The code derives an analytic conservative enclosure rather than treating the finite noise grid as a statistical confidence interval. A positive lower bound on the reference-difference denominator is required.

d = γGl − 4ε > 0; E = (Gnom/Gl)[2Gh ε + 4ε(|Re Y| + |Im Y|)]/d.

Here G_l and G_h bound the known reference, gamma bounds the common transfer magnitude from below, and epsilon bounds each real and imaginary noise coordinate. The normalized estimate is enclosed around the reference-scale interval[Gnom/G_h,Gnom/G_l] times Y, enlarged by E in each coordinate. The proof uses conservative triangle-inequality bounds for the two complex errors. It remains conditional on the circuit/load model and the external stability and noise assertions.
