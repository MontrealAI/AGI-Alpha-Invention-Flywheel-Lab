# Current sequence / channel-menu composition

The prior PR44 campaign remains historical, including realistic central ties and the cheap wiring-only gains. This edition preserves current common-production costing, ledger/source authority, channel contracts, snapshot optimization and platform policy. It does not adopt the negative two-opportunity repeat policy or change the incumbent default.

With sequence absent, existing one-opportunity joint/menu behavior is unchanged. With sequence present but no menu, the existing single-pilot forecast remains available. With both present, the same sequence window evaluator enumerates the actual declared menu contract IDs and one first action, using exact contract price/support, lead, expiry, active-tranche limits and already-observed contract state. Channel and capacity do not receive additive copies of the same delivery benefit. Future capacity is a conditional next-step proposal, not an authorized invoice. Current cash and earned money must cover reservations; forecast collections and reserve releases are never funds.

## Real transition semantics, explicitly hypothetical future

`sequence_channels.forecast_contract` copies observed ChannelBook state and evaluates paired baseline/new-tranche scenarios with fixed public surrogate seeds. It invokes the existing ChannelBook transition code: concurrent rights, overlap, cooldown, fatigue, activation failure/retries and expiry. It never receives the actual future environment seed. The independent operating auditor reconstructs the historical ChannelBook before rederiving the proposal; source hashes bind the code and native first invoice.

Four deterministic public seeds are authored uncertain scenarios, not a calibrated expectation or global optimum. Only a single future service window earns forecast value, while all interim contact attempts and realized-contact qualification are charged. This conservative omission of interim delivery value is disclosed, not proof those deliveries cannot happen. Full prices, buyer conversion, service mix and future rival quotes remain uncertain hypotheses. Expected value is not income. No transfer of private account custody occurs.

## Public development comparison

All 8 fixed worlds complete or publish explicit failure: one exposed seed × joint/sequence × single-pilot central control, menu central, menu overlap wiring and adverse menu. The proposed 16-world matrix was reduced before any new-source campaign outcomes to favor fast decisive iteration while retaining an adverse pair and wiring/control coverage. The menu wiring fixture has explicitly cheap short-lived contracts; it tests invoice identity, overlap and renewal mechanics, not market realism or economic superiority. The same source, cost contract and cohort are used within every pair. Compact native/operating audits and completed-resume results are public; no secret keys, side ledger or giant execution bundles.

Keep the existing incumbent unless comparable net results justify a change. No annualization, $3B attainment, actual commerce, autonomous invention or retained discovery-method advantage is asserted by this integration.
