# 🌌♾️ AGI ALPHA — One Revolution Is an Auditable Sequence of Effects

**Evidence scope:** native *simulated* commerce only. This edition adds a read-only witness to the existing Flywheel Harness; it does not operate accounts, install schedules, authenticate external buyers, invent mechanisms, or pay participants.

## The mechanical chain

A concrete commercial turn must have **ordered, source-bound native events**, not merely a circular picture:

`qualified order → executable delivered work → independently accepted result → native settlement → available earnings → native earned-only investment → qualified later work → later settlement`

The existing `connected_enterprise` remains the authority for actual simulated order execution, native `Account`/`JournalAccount` financial commitments and independent audit. The witness does not construct another runtime or ledger.

### What the new witness specifically proves

1. It runs `connected_enterprise audit` and `scoreboard` from the **explicitly trusted existing frozen source** against a **complete original native enterprise**. No new account is created.
2. It verifies the requested *single* business belongs to the registered and audited cohort; its recorded `RESULT.json` matches the source-index digest and its `GROWTH.json` was already rederived by canonical audit.
3. It checks accepted delivery, chronological order, and a corresponding native `release` action before treating an order as **collected**.
4. For each investment whose receipt actually says `EARNED`, it binds cost, kind, exact plan, native `finish` event sequence and prefix hash. Seed-funded spending does **not** qualify.
5. It checks whether collected work preceded the investment and whether later independently accepted **settled** work is source-linked to that investment, reconciling with the existing native investment-attribution record.
6. It outputs a compact evidence trace and an explicit verdict. Without an earned investment or later qualifying settlement, the witness reports an **open** or **absent** revolution, not a fabricated loop.
7. It includes the enterprise's recorded complete-cost *modeled* terminal profit, unrestricted earned balance, and no claim of real customers or real collections. Separate businesses are never pooled.
8. It explicitly refuses to infer **causal incremental profit** from chronological/source links, **inventive inheritance** without fresh successor comparisons, or **physical productive capability** from digital commerce.

### Why no self-funding claim is automatic

A collected order may precede an investment, but the witness cannot trace particular monetary units through a pooled native account. The account's source-bound `EARNED` commitment establishes the applicable current native funding rule. The witness records the distinction. Economic advantage requires a matched control under complete costs; an ordinary specialist may win.

An investment can be real within the **simulated enterprise** while having no beneficial successor, no new capability, or negative overall profit. A read-only witness cannot authorize an investment, make an asset valuable, transfer a licence, or grant a new production permission.

The output is create-only `REVOLUTION.json` outside native custody. `--trust-frozen-source` is required because the operation invokes source code stored in the selected native enterprise. Never use it on an untrusted downloaded archive.

## State machine and halt conditions

| Native condition | Decision |
|---|---|
| No source-verified collected order | No collection claim |
| Rejected deliverable | No accepted production claim |
| Only seed-financed capital | No earned-financed investment claim |
| Earned-financed investment but no later settled work | Open loop; do not claim complete revolution |
| Fully source-linked predecessor, earned investment, and successor settlement | **Native simulated sequence witnessed**; causal uplift still unknown |
| Native financial audit fails, source changes, result hash differs, journal prefix differs, unregistered world | **Refuse** |
| Real commerce, inherited discovery-policy benefit, or physical infrastructure without independent evidence | **Not established** |

## Invention loop remains separately testable

The second flywheel must prove `verified mechanism → retained scoped capability → fresh successor execution → matched no-inheritance/ordinary-reuse comparison → optional improved discovery procedure`. Commercial funding may pay for the investigation but funding provenance is not causal invention benefit. A successor begins with **empty current proof and authority**.

## Adversarial controls

The finite tests include invalid release timing, unaccepted work, seed-versus-earned financing, native action digest/prefix tampering, altered native investment attributes, double-counting attributable receipts, no earlier collection, no later settlement, untrusted CLI refusal, invalid path identifiers and never-asserted real revenue or funding authority.

The synthetic positive unit fixture is **authored**: it demonstrates contract behaviour, not observed native earnings. The hosted pipeline's existing seven-day native run demonstrates the read-only adapter against an actual canonical audit and can legitimately produce `NO_EARNED_FINANCED_INVESTMENT_IN_THIS_WORLD`. That negative conclusion is an important correct result, not a failed installation.
