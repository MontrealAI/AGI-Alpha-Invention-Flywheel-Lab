Set up the FRONTIER Ω companion

Extract the complete download. The companion needs Python 3.11 or later.

  1. Open the runtime folder and follow the steps for this computer below.
  2. Keep the companion running. Return to your existing mission and choose Connect desktop companion.
  3. Select Allow this tab in the companion window. The original mission stays open.
Windows

Open Launch-FRONTIER.cmd. Keep its window open.

macOS

This package contains a command-line launcher for trusted development setups. For browser-local or assisted work, return to My Frontier.

Linux

Open a terminal in runtime and run sh Launch-FRONTIER.sh. Keep its window open.

Use a pairing code

Open Use a pairing code in the companion’s browser page. Copy the code and paste it in your mission’s pairing form.

Configurer le compagnon FRONTIER Ω

Extrayez l’archive au complet. Le compagnon nécessite Python 3.11 ou une version ultérieure.

  1. Ouvrez le dossier runtime et suivez les étapes ci-dessous pour cet ordinateur.
  2. Laissez le compagnon en marche. Revenez à votre mission et choisissez Jumeler le compagnon.
  3. Sélectionnez Autoriser cet onglet dans la fenêtre du compagnon. La mission d’origine reste ouverte.
Windows

Ouvrez Launch-FRONTIER.cmd. Laissez sa fenêtre ouverte.

macOS

Cette archive contient un lanceur en ligne de commande destiné aux environnements de développement de confiance. Pour travailler dans le navigateur ou en mode assisté, revenez à Mon Frontier.

Linux

Ouvrez un terminal dans runtime et exécutez sh Launch-FRONTIER.sh. Laissez sa fenêtre ouverte.

Utiliser un code de jumelage

Ouvrez Utiliser un code de jumelage dans la page du compagnon. Copiez le code et collez-le dans le formulaire de jumelage de votre mission.
