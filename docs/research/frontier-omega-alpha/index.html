Release tested · 16 November 2026

Proving equivalence through an opaque rule

Lean 4.36 adds bv_decide +uf. The tactic can reason about two calls to a function whose implementation is unspecified when their Boolean or bit-vector arguments can be shown to agree.

We compared Lean 4.35 and 4.36 on two proofs involving a 32-bit expiry value. The new tactic discharged both on 4.36. Explicit congruence already proved both on 4.35. The independent decoder checked 69,640 words and gave a concrete witness for the deliberately false variant, which the new tactic rejected.

The result supports a reusable proof pattern for transformations behind an abstract interface. The experiment establishes neither a runtime speedup nor the correctness of the full reader.

CPU trial · 22 November 2026

A direct validator beats the local model trial

Can a local Qwen 27B model, with or without the GGUF adapter, select the valid edit for each of 12 constructed research-record cases? Both configurations used the same prompt, six CPU threads, and a 300-second deadline on one test host.

Neither model configuration completed its answer. A direct comparator tried the same candidate edits with the existing schema validator and solved all 12 cases in 1.15 ms.

Keep deterministic validation for this particular task. The result is from one run per configuration and leaves model quality on other hardware and other workloads open.

Receipt replay · 22 November 2026

Screening formal dependencies from published logs

Large Lean projects publish verification logs that can be screened before a team commits to a full build. We pinned seven public evidence files for seven declarations covering the Riemann and Dirichlet results and the Robin and Lagarias criteria.

The reusable parser and a separately implemented direct checker agreed with all 14 expected outcomes, including 12 altered or unregistered cases. The second cohort loaded the parser profile retained from the first.

This qualifies the checks on statement matching and allowed axioms in the selected receipts. The replay did not execute a proof kernel. The direct checker matched the retained method, so the comparison leaves a reuse advantage open.

Technical replay · 22 November 2026

Finding a documented 400 °C retrofit

Prusa’s HT Hotend added a documented upgrade path from a 290 °C stock nozzle limit to up to 400 °C on eligible CORE One configurations. The catalog explicitly excludes INDX.

Adding the dated retrofit to the catalog changed 7 of 24 test inquiries from no documented route to a retrofit candidate. The direct SQL comparison reproduced all 24 decisions. Three implementations also matched on all 18 cases in a separate process-screening test.

The evidence concerns catalog decisions for constructed inquiries. Physical performance, actual orders, payments and a causal benefit from reusing the first tool remain unmeasured.

A September 29 Prusa storefront capture already offered the upgrade for all five tested configurations. Using that catalog on both October dates gives 0 changes in 24 cases. The capture documents an offer. Fulfillment and daily stock remain unverified.
