# New exact-study contract

This is an **authored finite-model engineering study**, not a preregistered natural holdout or frontier-LLM performance test.

Purpose: determine whether source-grounded challenges expose omitted obligations and whether complete portfolio checking changes an apparently viable continuity promise. Construct a feasible technical/economic combination where supplied conditions allow; decline otherwise; retain capable conventional alternatives.

Freeze scope: two clients of four units each, suppliers P/Q/R, fixed commitments before activation, all registered activation scenarios, conditional delivery cash after upfront costs. Q compatibility requires an adapter and its pooled reservation price requires the separately modeled arrangement. Extra supplier-failure cases are distinct controls, not silently omitted stress paths.

Comparators: a separately coded oracle using all subset-capacity inequalities, with the same construction menu, prices, acceptance assumptions, scenario set and cash. An existing P+R route is eligible. No control is denied construction or coordination permissions.

The source-coverage exercise uses an authored required-item set, source IDs and presented output. It distinguishes material omission, irrelevant omission, invented source and false criticism; no natural semantic understanding is claimed.

All 192 parameter cases and nine named construction scenarios are retained. Complete model costs include all *listed* costs; they do not measure complete actual enterprise expenses. Positive prospective surplus is insufficient if the cash prefix is negative. Analytical cash records grant no operating authority.

The finite result, test suite and theoretical statements are reported separately from prospective book, customer, successor and meta-discovery experiments. A change in scope or acceptance must be recorded; a failed actual campaign cannot be repaired by silently changing its target.
