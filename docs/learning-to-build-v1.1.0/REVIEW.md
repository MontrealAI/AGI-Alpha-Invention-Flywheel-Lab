# Review record · Learning to Build 1.1.0

This record describes AI-assisted editorial and engineering review in the
author's preparation workflow. Separate implementations and review roles are
not external peer review or independent institutional certification. The
original 1.0.0 review and evidence remain preserved in that edition.

## Scope and substantive repairs

1. **An unavailable historical package cannot be silently reconstructed.** The
   continuation recovers the registered source branch and its immutable
   amendments, then identifies every new run as an exposed-data reproduction.
   Missing earlier outputs and costs remain unavailable. Focused historical
   failure replays establish the reported failure mechanisms, not the contents
   or complete cost of the absent earlier runs.
2. **A strong practical alternative needs actual operation.** The separately
   registered CellposeDINO source, model and runtime are restored by exact
   identity. All six classical choices are sealed before its inference begins.
   Its pretraining and learned stock differ from the classical arms, so it is
   not presented as a seventh equal-content causal arm. Possible pretraining
   overlap with the datasets remains unknown.
3. **Resume identity checks are not scientific recomputation.** The frozen
   pretrained producer checks saved PNG hashes during partial resume but trusts
   some saved metrics. The additive independent checker recomputes metrics,
   measurements, geometry, reference identities, field receipts and verdicts.
   It rejects a results file without the complete inventory seal. Registered
   producers are preserved rather than retrospectively patched.
4. **A stronger checker must bind its own scope.** The independent checker pins
   every registered producer, protocol and runtime dependency, rejects changes
   to its source during execution, and distinguishes full donor/calibration
   replay from the explicitly `LIMITED` saved-mask mode. One verification
   invocation was stopped after a checker schema improvement; its log is
   preserved and no verdict is attributed to it.
5. **Unexpected filesystem state must remain visible.** The observed completed
   classical directory contained residual copies of successor attempt files,
   byte-identical to canonical completed files. Their cause is unknown. The raw
   tree is preserved and rejected by strict inventory checking. A separate,
   explicitly mapped canonical checkpoint projection keeps all scores, stages,
   identities and measured costs unchanged; residual bytes are retained. An
   actual frozen-producer resume on that projection is recorded separately.
6. **Observation conversion needs an honest interface.** The emitted classical
   instrument expects scalar inputs. Its operating guide now gives the frozen
   `data.py canonicalize` command for RGB observations; the pretrained operator
   applies that same adapter internally. The generally lossy conversion does
   not recover original physical radiometry. The reference-outline decoder and
   acceptance criteria are not changed after results.
7. **Package usability must be tested before publication.** Review found that
   exact specialist installation and one-field inference were initially only
   exercised after release creation in the new workflow. The candidate package
   now receives that gate before qualified assets can be published. An explicit
   `--origin` distinguishes candidate-package operation from operation after an
   actual release download. The post-publication check remains separate.
8. **Failed hosted work must retain diagnostic evidence.** The workflow now
   retains setup receipts, pip reports and subprocess logs plus inference logs
   and failure receipts on both success and failure. An uploaded success JSON
   alone cannot substitute for the missing reason a failed command stopped.
9. **Integrity checks must cover adversarial cases.** Archive tests reject
   traversal, symlinks, duplicate members, altered bytes, rehashed incomplete
   inventories and existing extraction destinations. Independent scientific
   tests exercise reference geometry, metric denominators, type/schema errors,
   stale source bindings and forged saved evidence. Checks run under normal and
   optimized Python so correctness does not depend on `assert` statements.
10. **Contribution and evidence must be separated.** The paper's proposed
    contribution connects a complete construction witness with a controlled
    attribution test. It does not claim to originate systems integration,
    program learning, complementarity or transfer. The original conventional
    tie and the continuation's exhausted candidate bank remain results.
11. **A verifier failure must remain a failure until repaired and rechecked.**
    The first all-field neural audit reached a wrong key path while checking the
    pinned model-loading record: it is nested under `preflight.loading`, not a
    top-level `loading` field. The rejected receipt, measured work and exact
    earlier checker/driver sources are retained. The additive checker receives
    the narrow lookup correction and a regression for the observed schema.
    New full classical and all-field neural checks bind the corrected source;
    the earlier positive classical receipt remains separate. No registered
    producer, scientific criterion, model or output mask is changed.

## Verification records

### Separate continuation review and adjudication

Three additional review roles examined scientific integrity, construction mechanics,
and publication. They were separate assistant agents in the same session, not an
external audit or institutionally independent peer review. The evidence reviewer
did not author the original candidate, and the publication reviewer authored only
the narrowly identified setup repair after reviewing its failure.

The evidence review matched all 416 original raw paths to 278 canonical files and
138 preserved residual files, with no byte or size mismatch. It upheld the
reported scientific verdicts and found a material cost qualification: the
producer's false interruption flag reports the recorded ledger state, not proof
that the residuals arose without additional execution. The derived report and
manuscript now explicitly retain unknown residual-origin work and cost. The
original run state, producer report, measured timings and raw archive are unchanged.

The publication review reproduced a setup failure caused by an ambient enclosing
Git repository. The repaired installer recognizes an owning checkout only in the
canonical repository layout, otherwise protecting the extracted edition itself.
Seven focused tests pass in normal and optimized Python, including source-tree,
Git-worktree, relative-path and symlink protections. Actual inference from the
copied repaired candidate reproduced the retained first nucleus-test prediction.
The prior failed gate remains failed in the separate qualification packet. This
operation uses an exposed field and is not a fresh scientific confirmation.

The construction role froze the order/component diagnostic before executing it,
then separately froze one practical composition before its calibration scores.
The evidence reviewer did not author these programs. That reviewer verified both
archive inventories and source/result bindings, decoded only the four calibration
references through the separate checker, independently rescored all 20 new masks,
and replayed both programs against their frozen numerical endpoints. The metrics,
aggregates and verdicts agreed. The failed composition scored no test fields and
did not execute a new full raw-neural pipeline. Review preserved these limits,
including the coupled seed/foreground software branches and the cached-score
nature of the order experiment; it did not turn either diagnostic into fresh
confirmation or a claim of learned invention.

The evidence reviewer authored the portable projection utility. A different role
reviewed that utility and its focused tests and compared every one of the 416
reconstructed original files with the preserved original tree, finding no byte
mismatch. A reviewer-authored instrument is not independently validated merely
because it appears in an independent-review packet; this separate check supplies
the narrower implementation evidence. The strict raw rejection remains expected.

All substantive findings were resolved in the stated scope. No material scientific
disagreement is suppressed: the unresolved residual provenance, incomplete total
costs, exposed cases, unexecuted full repair pipeline, absence of an accepted
whole-cell successor and lack of a fresh learning-advantage comparison remain
explicit limitations. The additional review receipts and ledger identify the
work needed to reach these conclusions.

The exact scientific reports, raw rejection, projection mapping, measured
execution receipts, focused historical failures and recovery observations are
inside the compact reproduction archive, identified by its manifest. The
source-linked package manifest binds the paper, checker, tests and retained
evidence. Ordinary hosted checks and downloaded-release receipts record
publication status independently of scientific acceptance.

The canonical PDF is rendered and visually inspected during preparation.
Recompilation is compared for content, with byte equality required within the
same toolchain. A different TeX distribution can change PDF bytes without
changing the paper; no verification command silently refreshes the binding.

## Limits that remain

The independent checker does not rerun neural inference; the actual model run
and package operation are separate observations. It cannot authenticate a
historical clock, prove absent pretraining overlap, grant downstream commercial
rights, or substitute for an external beneficiary's acceptance. The actual
reproduction environment reuses selected exact-version system packages, and
unregistered transitive binaries are recorded rather than retroactively called
preregistered. No fully isolated historical environment is claimed.

The comparison tests a parameter update within a supplied finite construction
method. It does not establish a learned new algorithm, improvement of the update
rule itself, a causal artifact-enabled successor, general construction learning,
physical expansion, commercial adoption, receipts or profit. Missing total
costs remain unknown, not zero.
