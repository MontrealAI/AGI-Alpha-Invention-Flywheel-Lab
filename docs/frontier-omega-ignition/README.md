# FRONTIER Ω · Capturing the Exponential — Interactive demonstration

MONTREAL.AI × QUEBEC.AI · November 17, 2026

## Launch

Open `index.html` in a modern desktop or mobile browser. The experience is a single self-contained offline-capable file. No installation, telemetry, API credentials, account access, or network calls are required to run the demonstration. External source links are optional reference material.

## What actually runs

1. A visitor enters a specific company, idea, or ambition and selects an objective and time horizon.
2. A **finite, explicit, source-linked research catalogue** is ranked deterministically to reveal five frontier *hypotheses*. This is not live AI inference and the exploration-priority score is not an estimated commercial success probability.
3. The visitor selects a candidate and explores the **Eight Fundamental Mechanisms** with candidate-specific questions, alongside Transformational Intelligence and Learning to Build.
4. A real JavaScript decision instrument computes scenario economics versus a feasible alternative and no investment, then independently checks the result through enumeration, boundary cases, a forged-result test and an adversarial stress scenario.
5. A downloadable JSON evidence receipt records the mission, cited frontier triggers, assumptions, calculation and test outcomes.

## Scientific and commercial limits

Public sources establish specific reported frontier research advances (FlashProve, AlphaProof Code, Fable 5.2, Gemini 4 Carbon and the Scientist World preprint). **They do not establish that the derived product hypotheses were impossible to build five weeks earlier, that any buyer exists, that AI created the demo live, or that the products are profitable or fully autonomous.** The economic values are illustrative inputs, never realized returns. The research preprint has not been independently replicated by this demo. The independent verifier checks only the arithmetic of the economic gate; it does **not** verify the vendor research, prospective business results, or a cryptographic inference proof.

This demonstration is a transparent, working **frontier-to-decision experience**, not yet a general-purpose frontier-to-artifact autonomous construction platform. The bigger engine is an internal MONTREAL.AI research and commercialization ambition.

## Reproducibility

Run `python3 -m unittest discover -s tests -v` if Playwright and Chromium are available. Tests exercise the actual HTML in Chromium and include cases for custom input, five hypotheses, selection, economic recomputation, tamper rejection, and export.
