# FRONTIER Ω — IGNITION Construction Edition

MONTREAL.AI × QUEBEC.AI · 17 November 2026

A self-contained browser demonstration connecting a stated ambition to a bounded, executable decision instrument. FRONTIER Ω is being developed primarily for MONTREAL.AI's own use; any external engagements are selective and time-limited. This artifact creates no commercial or ongoing-service obligation.

## Start

Open `index.html` in a modern browser. No installation, account, API key or network request is required for the computations. Research links open external sources only when selected. No submitted text is uploaded by this application.

Bring an ambition through the existing four-step research-lead journey, then select **Build a first decision instrument**. Alternatively, go directly to **IGNITION**. Enter a purpose and capability name, define 2–6 integer reading values and choose upper-bound or interval questions. Run **Construct → challenge → verify**, then export the working HTML tool or its evidence record.

The exported tool handles individual reading pairs and batches, checks decoded answers against direct raw-input evaluation, and refuses unsupported rows. One invalid row rejects the whole batch. Editing a contract revokes current acceptance and disables export until reconstruction. The batch input limit is a browser resource guard, not a business-scale limit.

## What executes

- The supplied answer-signature compiler constructs an encoder, decoder and separation witnesses from the declared finite input domain and question family.
- The checker independently evaluates every declared question on every input, checks minimum label counts, and rejects deliberately corrupted decoders.
- A changed interval requirement exposes inadequate inheritance from the upper-bound capability. Fresh source readings are required; discarded information is not reconstructed from an old summary.
- The measurement studio uses exact rational arithmetic to search a declared quadratic-drift programme catalogue and choose a calibration/query pair for a supplied reuse horizon. The out-of-scope cubic stress remains a failure.
- Three earlier finite causal, economic and affine-construction experiments remain available with their own scope disclosures.

## What does not execute

The five research leads are a dated, authored catalogue with transparent heuristic ranking—not live AI research or proof that something was impossible 35 days earlier. The prose purpose is recorded, not semantically verified. The exported finite decision tool does not implement an arbitrary business ambition. No provider-model call, physical experiment, external transaction, verified customer acceptance, realized profit, general autonomous invention or comparative superiority is established.

Direct maximum/minimum methods tie the finite decision outputs. A conventional exact specialist can match the measurement construction. The reported acquisition units are not dollars, elapsed time or full commercial costs.

## Verify the exact bytes

Prerequisites: Node.js for core tests; Python 3 for the standard-library replay. Browser tests additionally require Playwright and Chromium already installed locally.

```sh
node --test tests/test_construction.cjs
python3 independent_check.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

`CHROMIUM_PATH` can select the Chromium executable; the default is `/usr/bin/chromium`. Browser tests render the self-contained source with Playwright `set_content` and exercise interactions and exported HTML. These are not production-host, direct-file-navigation, external security-audit or independent institutional qualifications.

The local continuation run passed 10 Node tests, 22 Chromium tests, and a separately implemented Python replay of 380 informative programmes, 144,400 reference/query pairs and 100 horizons. Current source hashes and evidence accompany the downloadable edition. Test counts are implementation evidence, not a measure of intelligence or commercial viability.

## Repository integration

The source is additive under `docs/frontier-omega-ignition/research-edition/`. `assemble.py` takes the existing `docs/research/frontier-omega-world-lab.html` and emits a new self-contained page into a new directory. It rejects missing or ambiguous source anchors and refuses to overwrite an existing output directory. It copies only its explicit source/test/documentation allowlist, never user manuscripts, credentials or account files.

```sh
python3 docs/frontier-omega-ignition/research-edition/assemble.py \
  --base docs/research/frontier-omega-world-lab.html \
  --output /absolute/new/frontier-preview
```

The website workflow checks the original site first, builds and checks the new edition, replaces only the staged World Lab page, then reruns the existing publication-boundary tests. A draft pull request does not deploy it. Review, merge and deployment remain separate decisions; this implementation grants none of those authorities.
