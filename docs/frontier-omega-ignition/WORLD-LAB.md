## Open the lab

Double-click `index.html` in a modern browser. No server, API key, subscription, account, network connection or installation is needed for the **offline functionality**. Clicking primary-source links requires an internet connection.

The experience has two distinct, clearly labeled layers:

**IGNITION · Visitor journey.** Enter an ambition or choose one of four samples. A transparent relevance heuristic selects five research hypotheses from real dated November 2026 announcements. Select a hypothesis and explore the actual names and questions of the Eight Fundamental Mechanisms from the supplied research. Generate a portable JSON research witness and a separate HTML acceptance specification.

**LIVE EXPERIMENTS · Demonstrable science and construction.** Three working studies present research methods behind the promise:

1. **Transformational Intelligence.** Enumerates both worlds across `2 × 2^12 = 8192` finite causal/intervention traces. The observational ceiling is 50%; the supplied active intervention policy identifies `8191/8192` correctly. An unrestricted optimal planner matches the policy. The model is authored; no LLM result is claimed.
2. **Invent the Economy.** Recomputes the exact, stipulated four-buyer case: expected contribution +120 illustrative units, with a prerequisite 900-unit prefunding cash path. Change buyer count, construction cost, qualification probability or actual starting cash and the decision can fail. Competent unrestricted commercial construction may reach the same arrangement. These are *not observed buyers, sales or profit*.
3. **Learning to Build.** Compiles arithmetic measurement instruments from the original 1.0.0 authored four specification schemas, with original coefficients and acceptance thresholds. Exhaustively checks 125 + 125 + 625 + 3125 = 4,000 input records against a separate reference interpreter. Downloads a real standalone HTML instrument for any selected task. The compiler is developer-supplied, not learned by AI; ordinary interpretation ties. No open-ended autonomous invention claim.

`independent_replay.py` is a *separate Python reimplementation* of the underlying finite experiments, using exact rational arithmetic for the market and the original public author-specified affine calibration rules. It writes `EVIDENCE.json`, including an SHA-256 checksum for the HTML. This checksum binds file bytes, not model provenance or third-party validation.
