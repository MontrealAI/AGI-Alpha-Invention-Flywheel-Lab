## Operate the candidate

Open the downloaded standalone exhibition in a browser. Switch languages, choose an opportunity, inspect a passage or table crop and download the instrument. The source language of a quoted passage is preserved. A full checkout also provides the original Pairing Lab. The private lab can serve the public exhibition from `/exhibition` and the Pairing Lab from `/showcase`. Public assets contain only recorded public outcomes and local interactive calculations.

From `products/frontier-omega-ignition` in a full checkout, with Python 3.11+ and Poppler installed:

```sh
python3 -B -m ignition reading-edition --source ../../docs/research/cycle-001.html \
  --pdf ../../docs/research/cycle-001.pdf --output /tmp/frontier-accepted-reading-edition
python3 -B table_desk/parser_matrix.py --observation table_desk/evidence/nemotron \
  --author ../../docs/research/cycle-001.html --output /tmp/frontier-accepted-table
```

Use a fresh output directory for each run. Open `index.html` in the reading-edition directory or open the CSV from the table directory. The [study guide](../../../../products/frontier-omega-ignition/reading_room_study/README.md) explains how to regenerate and compare full-markup editions. The [optional model instructions](../../../../products/frontier-omega-ignition/table_desk/NVIDIA-ARM.md) reproduce the CPU inference. The [exact-source workflow](../../../../.github/workflows/frontier-ignition-reading-room.yml) exercises actual downloads, languages, responsive layouts and the public server boundary.

## Costs, limits and the next decision

The concrete NVIDIA run loaded 2,523,266,640 bytes of weights and took 39.1139 wall seconds and 111.714 process CPU seconds on four inference threads, including input/model identity checks and model load. Tesseract took 1.016715 seconds summed over the twelve cell subprocesses, with preassigned geometry. The two timing scopes differ. Both programs required crop registration; Tesseract also consumed individual cell geometry. Dependency installation, acquisition and candidate construction, operator intervention, human review and complete service costs remain unpriced. The included model and hosted CI bills are unknown. The work used existing compute and public sources; there is no customer transaction or earned revenue.

The two-paper transfer establishes repeatable engineering on two public source pairs.
