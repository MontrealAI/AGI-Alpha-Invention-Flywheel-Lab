## What changed for an operator

A defined mission can use direct construction immediately. An exact trusted manifest can also be compiled locally with no inference. When a model constructs a repairable defective candidate, the private workbench records the failed attempt, discloses bounded diagnostic information to the builder and rechecks the repair against the same acceptance. The operator can separately request frontier research and a direct fallback. The previous research decision remains visible.

Open the private workbench, choose **Choose a self-hosted coding stack for a pilot**, then set the mean token allowance, number of attempts and required resolution. The selector learns the policy on calibration issues. A separate SQL procedure checks the locked selection, holdout results and token total. A new mission revision is required to certify changed inputs. The public exhibition uses a fixed licensed cohort and works offline. A private download supplies `mission-decision.json`; the recipient runs `python3 verify_decision.py` after extraction.
