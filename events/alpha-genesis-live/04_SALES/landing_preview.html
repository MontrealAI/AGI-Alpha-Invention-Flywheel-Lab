Questions

What participants should know

Do I need programming skills?

No. The attendee lab uses a standalone browser instrument and workbook. The presenter handles the technical agent execution.

Will my own challenge be built in full during the event?

The live, independently checked build uses a bounded, disclosed business scenario. The audience helps choose priorities and strategy. Each participant learns to frame a personal challenge for a later safe, testable experiment; arbitrary enterprise systems cannot be promised in a two-hour session.

Do I need ChatGPT Pro or an API key?

No participant account is required for the core exercise. The presenter will use an officially signed-in Codex CLI connection for the live agent, subject to successful pre-event qualification.

What does the evidence prove?

The independent computation checks the defined synthetic case and disclosed what-if assumptions. It does not prove actual vendor recovery, financial returns, audit certification or permission to transact.
