## Implementation in this package

- `engine/` is an original, previously constructed bounded tool-using synthetic procurement example, bundled as editable local source with tests, reference fixtures and a read-only broker.
- `00_STAGE/strategy_agent.mjs` is the second model-backed reasoning stage, confined to three allowed conditional scenarios.
- `00_STAGE/scenario_engine.mjs` recomputes the four test states under the unchanged synthetic policy. Source evidence and authored *hypothetical changes* must not be conflated.
- `00_STAGE/build_live_studio.mjs` writes a standalone HTML instrument only if the baseline receipt was independently reverified. Its browser button freshly cross-checks totals against embedded lines; the full source-policy check occurs in the separate `verify_receipt.mjs` process.
- `00_STAGE/run_show.mjs --mode preview` and its packaged HTML are **scripted preview** products. `--mode codex-pro` requests actual Codex inference after official account sign-in and must be qualified on the presenter's computer. A fake Codex protocol test does not establish real account access.
