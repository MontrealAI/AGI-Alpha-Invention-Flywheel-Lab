# Launch qualification — the event earns the right to claim LIVE

## The essential five checks

1. **Real authenticated agent:** on the presenter's computer, `codex login status` confirms official ChatGPT sign-in; a full `run_show.mjs --mode codex-pro` records actual model calls and produces a complete 8-order agent receipt.
2. **Independent baseline:** `engine/verify_receipt.mjs` returns `CHECKS_PASS`, 8 checked lines, complete tool coverage; the last run's four source-file identities are pinned.
3. **Constructed instrument:** the studio opens in the presentation browser, switches 3 strategies, exposes explicit assumptions, exports a JSON dossier, and remains usable without an internet connection.
4. **Human participant:** one person unfamiliar with the tool completes workbook challenges and exports a working artifact; one deliberate input change produces a different checked result.
5. **Event operations:** published date/time, correct Toronto timezone, accessible Zoom link, Eventbrite paid checkout test, refund/recording notice, support contact and speaker audio/screen share all confirmed.

If any live-model check is incomplete, market only the reproducible workshop elements already qualified; do not claim a verified live connection until it actually occurs.

## The quality boundary

No one needs to publish negative development logs to a marketing page. The presenter does need the confidence that actual permissions, tool execution, verification and participant experience have been exercised. This checklist exists to prevent a good product from being undermined by an avoidable live delivery error.
