# The live audience challenge — ambitious, but deliverable

The title promises an ambition becoming something real. Do not dilute that by allowing unbounded audience instructions to derail the actual working demonstration.

## Ask one memorable question before the event

“What consequential professional outcome would you pursue if a capable AI agent could investigate, build and test a small instrument for you?”

Request a **one-sentence high-level objective**, with no private documents, account details, names of clients, credentials, personal information, proprietary code or regulated advice. The organizer may select representative submissions and paraphrase them only with permission.

## Translate the room into an executable challenge

For this event's first live experiment, preserve the eight-order fictional Northstar case and its frozen verification rules. Give the audience a meaningful choice:

- **TIME:** Can a launch recover enough supply and delivery confidence?
- **COST:** Can we reduce the amount of approved commitment that remains blocked by commercial/quality exceptions?
- **CONFIDENCE:** Can we construct a verified instrument a team can use to inspect conditional recovery paths?

A show of hands, Zoom poll or permitted chat response chooses a priority. The presenter executes the corresponding `--focus time|cost|confidence` mode. Ask participants which assumption would most change their mind about the selected path.

## The honest boundary

This is a live adaptation of a **bounded, rehearsed** mission, not unrestricted guaranteed implementation of any arbitrary public challenge. A participant's personal ambition becomes their own five-move experiment blueprint in the workbook. The promise is an actual construction on a consequential case and a transferable method.

## In-show micro-interactions

1. Ask the room to predict what the model will discover before tool use starts.
2. After the first verified result, ask whether to stop at “six holds” or explore what could improve the outcome.
3. Let the room select the alternate path in the working instrument.
4. Ask for an independent test rather than approval by applause.
5. Close by letting each attendee state a worthwhile next experiment.
