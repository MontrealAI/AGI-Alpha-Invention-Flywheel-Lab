The first SciPy/HiGHS solve exceeded its configured solver time without a usable

CP-SAT optimization uses cost coefficients rounded at 1e-4 yuan per unit. Source
client costs are recomputed using original coefficients. A conservative 4*total
pieces*maximum coefficient-rounding error bounds the source-objective difference.
OPTIMAL concerns the rounded formulation. Bounds require correct/full model
encoding; they are not independent formal proof certificates. Feasible successor
outputs have open optimization gaps. Parallel search can return different valid
solutions on replay; recorded hashes bind delivered files, not all future runs.
